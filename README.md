# Dark Pixel Survivor

一款处于设计前期的独立 PC 动作肉鸽项目。

目标体验是俯斜视实时移动、密集但可读的法术与投射物、清晰的碰撞空间，以及能够直接改变弹道、范围、攻击节奏和屏幕形态的高自由度构筑。

## 当前阶段

项目目前处于**整体架构与系统设计阶段**：

- 产品定位与宏观循环已经建立；
- 武器系统已经形成首份完整详细报告；
- 角色技能进化网络已确认开放式拓扑、混合窗口、分层公开、角色共核、每条母路线的独立战斗闭环，以及开放式节点材料与力量载体；
- 角色来源武器附效由角色持有，路线不绑定具体武器或武器类别；已确认普通换装状态、逐效果手位／覆盖、有限次数出手扣除，以及部分范围命中与状态重施边界；其余生命周期和结算仍待定；
- 角色节点采用直接合法池随机选择；相关母路线可开辟有自身形态的融合路线，多数节点单级、部分关键节点可升级；角色主动每技能一槽，仅在指定时机调整携带，原版／上位默认可共携、具体冲突例外；
- 常规角色节点选择不放弃；机缘可提供本局留存的整组重骰，用于属性、角色节点、武器进化和常规附魔候选；
- 最终引擎、2D／2.5D／3D 表现与实现架构尚未锁定；
- 本仓库暂不包含旧 Phaser 浏览器原型代码。

设计确认和功能实现是两种不同状态。文档中的“已确认”只表示规则已经进入目标设计，不代表对应功能已经完成。

## 核心支柱

- 每个角色拥有独立技能进化网络、专属武器家族和个人故事关卡。
- 角色网络不设固定主／副路线；有限机会控制广度，局部前置控制深度。
- 普通经验每级提供基础属性，配置里程碑额外打开角色窗口；精英、Boss、剧情与机缘提供稀有角色机会。
- 部分角色技能需要本局战斗行为或特殊机缘，部分 A 级武器只能由配置的机缘或掉落获得。
- 常规条件完整公开，稀有内容先给线索并在发现后写入图鉴；核心构筑不依赖完全隐藏条件。
- 同一角色的路线共享角色共核，但每条母路线必须拥有独立、完整且不依赖融合的战斗闭环。
- 相关母路线通过相关子节点开辟具有区分度的融合路线；融合入口和后续也可进入常规合法候选池，特殊来源要求按具体节点执行。
- 主动、被动、新增效果、进化已有技能，以及直接技能、自身强化、武器攻击附效等力量载体，都只是开放式构成材料，不能替代路线玩法差异。
- 路线可以引入局部状态或规则，但不强制使用数值资源或统一的积攒—消耗循环；专用 HUD 条只在确有持续决策需要时增加。
- 角色来源效果可以通过公开接口表现于武器攻击，但不会因此变成武器的先天词、附魔、`+强化`、命名进化、神通、锻造或兵装共鸣。
- 角色持有效果并动态作用于当前合法武器；武器可以与路线更契合，但不能成为母路线成立的绑定前提。
- 普通经验、角色技能成长和命名武器成长分层处理。
- 玩家持有正手与副手；正手手动操控，副手自动攻击且行为不同。
- D/C/B/A/S 是不同命名武器的固定底盘，不是同名武器不断变色。
- 武器合法直接上位只有一两个时全部展示，超过两个时随机二选一；可用骰子整组重抽，也可消耗机缘放弃并获得当前武器 `+1`。
- D/C/B 来源进化的 `+`减一级、最低归零；非完全直系的适用附魔按等级比例折损、归零移除，不兼容附魔直接失去，具体比例与取整待定。
- 常规附魔在合法候选充足时默认三选一，已有可升级项仍可入池，升级只培养原有效果；附魔以适度的局部效果补充与组合为主，可明确增加穿透或附带低伤害燃烧；常规附魔先看候选再选目标并当场应用，同名可升级，每个候选至少有一个当前合法目标。
- 多个 A 级同参可以逐步为同一把 S 级武器提供不同神通。
- 同参位只收目标 S 的同参 A，位内武器不参战；默认无需供体亲自参战，少量可配置炼入前战斗淬炼，参战仍须使用正手或副手。
- 合法同参位 A 可接受常规附魔；后续炼入已有 S 仍只带所选一条及当前等级。零附魔供体满足其他条件后正常炼入并加入神通，没有附魔带入；S 锻造的具体机会和代价仍待定。
- 神通负责主动、弹道、触发和规则变化；S 整体锻造只负责高代价数值完善。
- 局外成长以角色、路线、武器、剧情、外观和挑战的横向解锁为主，不提供永久数值碾压。
- 大多数标准关卡以成熟 A 构筑足以通关为目标；S 极稀有且强力，部分神通重构规则，A 难以支撑很深无尽。
- 无尽延伸已有系统：普通经验与 S 普通 `+强化`共同承接持续数值成长；大多数属性可无限成长，普通暴击率有效到 100%，普通属性升级中同一种、同规格奖励的基础增量不因累计投入自动缩水。具体属性例外、各品级 `+`与附魔上限仍待定；S 整体锻造仍有限。

## 与旧原型的边界

旧项目 `dark-pixel-survivor-mvp` 使用 Phaser、TypeScript 与 Vite 验证过部分战斗循环，但它不是本项目的最终技术架构。本仓库从目标独立游戏设计重新出发，不自动继承旧原型的浏览器平台、单场景结构、五分钟关卡或写死内容。

旧原型当前仅作为体验证据和历史参考保存，不与本仓库混合提交。
