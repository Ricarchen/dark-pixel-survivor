## 1. 执行摘要

每个角色拥有一张独立、规模可变的技能进化网络。网络由若干母路线构成；每条母路线都必须能够独立形成有效构筑终点，只有主题、机制或战斗场景相近的路线才拥有手工设计的融合关系。

局内采用**开放式多路线投资**：玩家不需要预先声明主路线或副路线，也不会在中期被系统强制锁定一条主路线。任何已经局外解锁、满足局部前置并符合本次候选条件的路线，都可以继续进入随机候选池。玩家可以专精一条路线，也可以同时发展多条路线。

开放不等于无成本。专精与广度之间的张力由两件事产生：

1. 一局内角色成长机会有限，投资更多路线会稀释能够投入单一路线的机会。
2. 深层节点具有局部前置，想抵达某条路线的高阶节点或终点，必须在该路线中持续投入。

这套网络仍然服从肉鸽随机性：玩家能够规划，但不能保证目标路线或融合必然出现。它也不与武器进化混为一体；角色网络塑造角色本身，武器谱系与神通塑造具体武器。

当前报告已经确认系统边界和网络拓扑，但尚未确认成长窗口来源、节点类型、候选生成细则、主动技能槽、融合门槛与血法师具体内容。未确认部分不会为了形成完整文档而虚构数值。

## 2. 玩家体验目标

### 2.1 自由来自可进入多条路线

玩家在同一局中可以根据随机结果和战况改变方向：

- 开局尝试一条路线后，仍可转入其他路线；
- 已经深入一条路线，不会自动关闭其余路线；
- 可以用多路线广度寻找协同，也可以牺牲广度追求单路线终点；
- 发现适配的融合机会时可以横向连接，但没有融合也能完成构筑。

### 2.2 选择必须同时有机会成本和适应空间

网络不能变成“迟早全点满”的传统技能树，也不能变成开局选择职业后一路照表加点。有限机会使每次选择具有成本；开放候选又允许玩家在随机不利时调整，而不是因为没有抽到唯一正确节点而让整局失效。

### 2.3 成长结果必须改变战斗方式

角色路线不能只提供攻击力、生命或冷却等基础数字。路线的中高阶结果应改变角色资源循环、风险承担、移动方式、施法行为、防御逻辑、召唤关系、主动技能或角色状态，并在战场表现上可辨认。基础数值主要由普通经验升级承担。

### 2.4 网络必须属于这个角色

路线应先来自角色身份、故事阶段、核心矛盾和战斗习惯，再转化为机制。不同角色可以拥有不同数量、形状、难度曲线和融合密度的母路线，不建立一张所有角色共用、只替换名称与特效的通用树。

## 3. 职责边界

| 系统 | 负责内容 | 明确不负责内容 |
|---|---|---|
| 普通经验升级 | 生命、防御、移动、基础伤害等通用基础属性 | 角色母路线终点、武器进化、S级神通 |
| 角色技能进化网络 | 角色资源、状态、移动、施法、防御、召唤、角色主动及角色路线融合 | 命名武器品级、A级同参、S级武器神通 |
| 武器系统 | 正副手行为、D/C/B/A谱系、附魔、同参、S神通与锻造 | 角色技能节点和角色路线终点 |
| 关卡与奖励导演 | 在一局中提供角色成长机会并控制总预算 | 改写网络拓扑或临时发明角色节点 |
| 局外解锁 | 解锁新角色路线、融合边、剧情与挑战 | 永久增加角色路线数值或替玩家点亮节点 |

### 3.1 与武器系统的接口

角色网络和武器系统可以通过公开事件、状态标签、资源变化、契合度和候选权重产生协同。例如角色节点可以发出“主动损失生命”“完成位移”“进入特定姿态”事件，武器可以监听并响应。

接口协同必须遵守以下边界：

- 角色节点不能算作 A 级仙基、同参材料或一道 S 级神通；
- 角色路线终点不能与武器神通再次合并成共同上位等级；
- 角色可以影响武器获取或契合，但不能改写通用武器固定的神通谱；
- 专属武器可以更紧密地读取角色事件，但离开特定角色后仍要满足其报告中声明的基础运行规则；
- 角色主动与武器主动的槽位和输入优先级尚待专门确认。

## 4. 术语

| 术语 | 当前定义 |
|---|---|
| 角色网络 | 某个角色独有的整张局内技能进化图 |
| 母路线 | 能够独立发展并抵达有效终点的一条主要成长方向 |
| 路线投入 | 玩家在本局已经选择并生效于某条母路线的节点集合 |
| 深度前置 | 进入较深节点前必须满足的该路线局部投入或状态条件；具体语法待定 |
| 路线终点 | 一条母路线自身能够完成的高阶结果，不依赖融合才有价值 |
| 融合关系 | 两条或多条相近路线之间由内容作者显式配置的横向联系 |
| 角色成长机会 | 打开一次角色网络选择窗口的机会；来源和数量尚未确认 |
| 合法候选池 | 在当前角色、本局解锁状态、局部前置和其他已确认条件下可以被抽取的节点集合 |
| 候选组 | 一次成长窗口中从合法候选池随机呈现给玩家的有限选项；数量尚未确认 |
| 开放式投资 | 不设全局主／副路线槽位，也不以中期承诺关闭其他母路线的结构 |

“节点层级”“质变节点”“突破节点”等词尚未成为正式类型；只有在后续节点语法讨论完成后才会加入规则表。

## 5. 已确认的网络拓扑

### 5.1 独立角色网络

- 每个角色有自己的网络定义和稳定 ID 空间。
- 不同角色不共享同一组母路线；相似主题也必须根据各自身份重新定义。
- 母路线数量是逐角色配置，不存在全局固定五条的要求。
- 每条正式母路线都能独立抵达一个可用终点。

### 5.2 开放式多路线投资

局内不设置“主路线槽”“副路线槽”或“最多进入两条母路线”等全局限制，也不要求玩家在中期宣誓或锁定唯一主路线。

一次角色成长机会生成候选时，候选资格按节点自身条件判断，而不是按“是否属于已选主路线”判断。因此：

- 投资路线 A 不会仅因全局路线锁而关闭路线 B；
- 玩家此前没有投资某条路线，不代表后续永远不能进入它；
- 满足局部前置的不同路线节点可以同时存在于合法候选池；
- 玩家可以从专精转向广度，也可以停止扩展并继续深化已有路线；
- 系统不会保证任一特定合法节点在某次或某局必然出现。

开放式投资禁止的是**全局路线名额限制**。它不预先否定单条路线内部未来可能出现的局部互斥节点、一次性取舍或剧情选择；如果采用，这些关系必须逐节点显式配置、提前向玩家披露，并且不能偷偷退化为整张网络的主／副路线锁。

### 5.3 广度与深度的成本

开放式投资通过机会预算和深度前置形成自然成本：

- **广度成本**：在更多路线中选择节点，会占用同一局有限的角色成长机会；
- **深度成本**：高阶节点和路线终点需要满足该路线的局部前置，不能从零投入直接跳到终点；
- **随机成本**：合法不等于必得，玩家可能需要根据实际候选调整计划；
- **无硬锁补偿**：系统不再额外用路线槽或中期锁定惩罚跨路线尝试。

具体机会数量、深度层数、前置形式和随机权重仍待关卡节奏与节点语法共同确定。

### 5.4 融合是显式横向连接

- 只有主题、机制或战斗场景确实相近的路线才配置融合关系。
- 没有融合关系的路线可以并行发展，不会因此成为错误搭配。
- 每条母路线在没有融合时仍须成立，融合不能成为修复废路线的隐藏配方。
- 融合是开放网络中的额外横向结果，不要求所有路线两两连接。
- 默认不会因为出现融合资格就自动删除原路线投入；融合的具体进入条件、是否可逆以及后续节点如何生长仍待确认。

## 6. 局内主流程（当前可确认部分）

```text
进入角色个人关卡
        ↓
载入该角色已在局外解锁的网络内容
        ↓
战斗并获得一次“角色成长机会”
        ↓
根据本局状态建立跨全部母路线的合法候选池
        ↓
从合法池随机产生有限候选组
        ↓
玩家选择一个候选
        ↓
节点生效，记录路线投入并重新计算后继／融合资格
        ↓
继续战斗；后续仍可深化原路线或进入其他路线
        ↓
在标准局形成至少一个清晰的高阶角色构筑结果
        ↓
通关、失败或进入无尽
```

当前不能把以下步骤写死：角色成长机会由什么事件产生、一次出现几个候选、能否刷新或放弃、没有合法候选时如何处理、节点是否可以升级、融合是否占用普通机会。这些问题分别保留在第 14 节。

## 7. 随机候选的不变量

候选算法尚未确定，但未来方案必须满足：

1. 候选从当前合法池产生，不从角色未解锁或前置不合法的节点中伪随机展示。
2. 合法池横跨全部可进入母路线，不能因为玩家先点了某条路线就默认屏蔽其他路线。
3. 随机性必须真实影响构筑，不能暗中保证玩家预定路线完整出现。
4. 每个候选被独立选择时都应有可用价值，不能只作为等待隐藏融合的空白材料。
5. 候选数量不是全局固定的“三选一”；常规、精英、Boss、剧情等窗口是否使用不同数量仍待确认。
6. 防止候选污染、连续重复或完全无关选项的算法，只能在节点语法和机会预算明确后设计。

## 8. 标准局与无尽模式

### 8.1 标准局

标准局应让玩家有机会形成至少一个清晰的角色高阶结果，但不承诺点满整张网络。选择广度意味着可能放弃单路线终点速度；选择深度意味着减少横向适应和融合机会。标准局中的实际可获得节点数、可完成路线数与融合密度尚未确认。

### 8.2 无尽模式

无尽可以继续提供角色成长机会，使玩家探索更多母路线和明确存在的融合关系，但不能让网络无限产生无意义的小数值节点。角色网络在无尽中的上限需要与多神通 S、锻造、敌人强度和屏幕可读性共同设计。

无尽中的更多投入不转化为局外永久数值；下一局仍需重新构筑。

## 9. 局外解锁的作用

高难度、角色故事、挑战和其他横向进度可以解锁：

- 新母路线；
- 某条路线的新节点或分枝；
- 已明确设计的融合关系；
- 新的角色主动、表现、剧情与挑战条件。

解锁只让内容进入未来局内的可用集合，不会直接替玩家激活节点，也不会永久增加伤害、生命等数值。随着内容池扩大，如何控制候选污染和解锁后稀释需要单独设计，当前尚未确认。

## 10. 信息披露与 UI 要求

未来选择界面至少需要让玩家在确认前理解：

- 候选属于哪名角色和哪条母路线；
- 当前已投入的路线与节点；
- 候选是开路线、深化路线、路线终点还是融合相关内容；
- 已知的前置、局部互斥、代价和不可逆结果；
- 该选择如何改变角色行为，而不只显示数值；
- 某条融合关系是公开、待发现还是尚未解锁。

UI 不应要求玩家先把某路线标成“主路线”才能选择其节点。网络总览可以帮助规划，但不能承诺随机候选一定按总览顺序出现。

## 13. 验证不变量

未来原型和测试至少应能验证：

- 选择路线 A 的普通节点后，路线 B 不会仅因“已选主路线”而从合法池永久消失。
- 同时投资多条路线不会触发隐藏的路线数量上限。
- 玩家选择广度时消耗真实成长机会，不能无成本收集所有浅层节点。
- 深层节点不会在局部前置未满足时进入合法池。
- 每条路线在完全没有融合的情况下仍能形成可用终点构筑。
- 未配置融合关系的两条路线能够并行运行，但不会自动生成融合效果。
- 角色节点不会修改武器品级、生成武器神通或替代同参材料。
- 局外解锁不会让节点在开局自动生效，也不会带入永久基础数值。

## 14. 待定问题与讨论顺序

### 14.1 下一项：角色成长机会来源

需要确认角色成长机会主要来自：

- 普通等级里程碑打开独立角色窗口；
- 精英、Boss 和剧情事件；
- 或两者分工的混合结构。

这项决定会反推标准局机会总数、路线深度、融合稀有度以及角色成长是否与武器重大机会竞争。

### 14.2 后续问题

1. 节点类型、深度结构、升级方式、局部互斥和终点语法。
2. 候选组数量、权重、防重复、刷新、放弃和放弃补偿。
3. 融合资格、出现窗口、是否占用普通机会、可逆性和洗点。
4. 角色主动技能槽位、学习、进化以及与武器主动的输入关系。
5. 路线如何改变角色模型、动画、VFX、音效和状态可读性。
6. 标准局与无尽中的机会预算和网络完成度。
7. 用血法师建立首个完整角色内容包并验证通用语法。

## 15. 未采用的全局方案

- **固定主路线＋副路线槽位**：未采用。它能降低平衡与 UI 难度，但会把高自由度构筑压缩成预设职业模板。
- **前期开放、中期强制承诺一条主路线**：未采用为全局规则。它能形成清晰阶段感，但会关闭随机转向空间，并可能让前期投入被动失效。
- **所有路线自由获取且最终全部点满**：未采用。开放路线不等于取消机会成本；有限机会和深度前置必须继续存在。
