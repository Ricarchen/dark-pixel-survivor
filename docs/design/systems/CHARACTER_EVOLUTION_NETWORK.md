## 1. 执行摘要

每个角色拥有一张独立、规模可变的技能进化网络。网络先定义所有母路线共同继承的“角色共核”，再由若干母路线围绕共核建立不同且完整的战斗闭环。每条母路线都必须能够独立形成有效构筑终点。有关联的母路线可以通过各自相关子节点开辟融合路线；融合路线拥有自己的身份、战斗形态与后续成长，并与源母路线及其他路线保持区分度，不能用孤立的机制结果代替。

局内采用**开放式多路线投资**：玩家不需要预先声明主路线或副路线，也不会在中期被系统强制锁定一条主路线。任何已经局外解锁、满足局部前置并符合本次候选条件的路线，都可以继续进入随机候选池。玩家可以专精一条路线，也可以同时发展多条路线。

开放不等于无成本。专精与广度之间的张力由两件事产生：

1. 一局内角色成长机会有限，投资更多路线会稀释能够投入单一路线的机会。
2. 深层节点具有局部前置，想抵达某条路线的高阶节点或终点，必须在该路线中持续投入。

这套网络仍然服从肉鸽随机性：玩家能够规划，但不能保证目标路线或融合必然出现。它也不与武器进化混为一体；角色网络塑造角色力量以及角色使用战斗载体的方式，武器谱系与神通塑造具体武器本身。

角色成长采用**共源分窗的混合制**。击杀与拾取推动同一条普通经验进度：普通等级窗口负责基础属性；配置的经验里程碑额外打开独立的常规角色窗口。精英、Boss、剧情与特殊机缘补充较稀有的突破、融合或其他重大角色机会，但融合入口及后续节点也可以按自身条件进入常规角色窗口。系统不再建立第二条常驻“角色技能经验条”。

并非所有技能节点只靠里程碑抽取。具体节点可以要求本局战斗行为，或限定由某种特殊机缘提供。系统必须区分“内容已在局外解锁”“本局满足候选资格”“候选实际出现”和“节点已经获得”，不能把满足条件自动误写成已经拥有技能。

特殊条件采用分层公开：常规路线完整展示要求和进度；稀有节点、融合与特殊来源初次至少给出可追寻的来源或剧情线索，首次发现后在图鉴中永久公开完整条件；只有极少数非核心彩蛋可以完全隐藏。知识公开不会改变候选概率或提供局外战斗力。

当前报告已经确认系统边界、网络拓扑、成长窗口分工、特殊资格、角色共核、路线闭环、局部规则、最低节点结果形式与角色来源武器附效的所有权。这类效果由角色持有，动态作用于当前合法武器；母路线不能以绑定具体武器实例或某类武器为成立前提，但允许武器与路线存在契合差异。普通换装与主副手切换的角色侧准备和冷却、普通换装后的已施加效果、暂时无载体时的角色计时，以及部分手位、适用条件与发动扣次规则已经确认，见第 3.2 节。

有限次数强化默认按一次符合条件的发动扣一次，出手即消耗，挥空不返还；同次覆盖整次还是指定部分由具体强化定义。中毒与燃烧可以共存，但二者的持续伤害不能互相施加、叠加或刷新另一状态。合法武器自身的范围、穿透、弹射或分裂攻击仍按具体附效条件处理实际命中；同一效果重施时如何刷新、叠层或独立持续也逐效果声明。

随机成长窗口先筛出满足解锁、前置、局部互斥、行为与来源条件的实际合法节点，再直接抽取有限具体候选。技能进化和前置逐技能／节点设计；多数节点单级，部分明确设计的关键节点可以多级，等级提升与后继分枝可以并行。角色主动的“已经获得”与“当前携带”分开：玩家选择携带，每个主动占一个有限槽位，且只在指定调整时机更换。特殊机缘可以调整已选节点，默认从新生成的合法随机候选中改选，具体调整范围与依赖处理仍待定。

已经获得的角色主动原版与上位版本默认可以共同携带，各占一个槽；明确配置的局部冲突可以互斥，不能仅凭版本关系禁止共携。常规角色节点选择窗口不提供放弃；部分机缘可以提供在本局留待以后使用的重抽机会或道具，使用时整组重抽，优先避开紧接着的上一组候选，合法池不足时允许重复。同一重抽机会支持普通属性选择、角色节点选择、武器命名进化候选选择和常规附魔候选选择（`GROW-13`），具体适用入口与未决细节见第 6.2 节。

玩家后天附魔的定位、常规候选获取与同名升级、先看候选再选目标、当场应用、同参位目标资格、候选至少可用于一个当前合法目标及共享重抽已确认，`ENCH-Q03` 部分解决，详情由武器报告负责。当前下一项跨系统讨论是常规附魔整个合法候选池为空时如何处理（`ENCH-Q04`），不再重开已经解决的原版／上位版共携或常规角色节点放弃问题。角色主动槽数、指定调整窗口、版本保存与等级转移、重抽细则、节点改选、其他生命周期、完整触发／递归与结算、UI／存档及具体角色内容仍待确认。未确认部分不会为了形成完整文档而虚构数值。

共同阶段不会决定所有路线采用同一种流程。每条母路线必须先建立“路线身份契约”，用共核联系、战斗闭环、空间命题、成长形状、获得节奏、机制质变和终点表达说明它为何独立存在。主动、被动、新增效果和进化既有技能只是构成闭环的材料；直接技能、自身强化、武器攻击附效等力量载体也只是开放示例，均不能替代路线身份。

## 2. 玩家体验目标

### 2.1 自由来自可进入多条路线

玩家在同一局中可以根据随机结果和战况改变方向：

- 开局尝试一条路线后，仍可转入其他路线；
- 已经深入一条路线，不会自动关闭其余路线；
- 可以用多路线广度寻找协同，也可以牺牲广度追求单路线终点；
- 发现适配的融合机会时可以横向连接，但没有融合也能完成构筑。

### 2.2 选择必须同时有机会成本和适应空间

网络不能变成“迟早全点满”的传统技能树，也不能变成开局选择职业后一路照表加点。有限机会使每次选择具有成本；开放候选又允许玩家在随机不利时调整，而不是因为没有抽到唯一正确节点而让整局失效。

### 2.3 成长结果必须改变战斗方式

角色路线不能只提供攻击力、生命或冷却等基础数字。路线的中高阶结果应改变角色行为、状态、运行规则、可选资源循环、风险承担、移动方式、施法、防御、召唤或武器攻击的角色来源附效，并在战场表现上可辨认。基础数值主要由普通经验升级承担。

### 2.4 网络必须属于这个角色

路线应先来自角色身份、故事阶段、核心矛盾和战斗习惯，再转化为机制。不同角色可以拥有不同数量、形状、难度曲线和融合密度的母路线，不建立一张所有角色共用、只替换名称与特效的通用树。

### 2.5 路线必须拥有独立身份

共同四阶段只保证一条路线具有完整成长弧线，不负责制造差异。差异由路线自己的核心决策、战斗闭环、空间关系、成长流程和终点表达产生。同一角色的两条路线如果能够在只替换名称、颜色、伤害类型或节点材料比例后互换，就应当合并或重做，而不是继续作为两个候选稀释池子。

### 2.6 共核统一角色，闭环区分路线

同一角色的母路线必须共享主题与底层核心规则，使玩家无论怎样跨路线投资都仍在扮演同一个角色。在此基础上，每条路线必须让玩家持续关注、操控和反馈于不同的战斗关系。

路线可以引入局部状态、场地对象、动作规则、标记或资源，但不强制建立新的数字条，也不默认套用“积攒—消耗”循环。力量可以落在直接技能、角色自身、武器攻击或其他符合主题的载体上；这些载体不是固定路线分类，也不能仅靠换载体证明路线不同。

### 3.1 与武器系统的接口

角色网络和武器系统可以通过公开事件、状态标签、资源变化、攻击／命中事件、契合度和候选权重产生双向协同。例如角色节点可以发出“主动损失生命”“完成位移”“进入特定姿态”事件供武器响应；角色来源效果也可以读取武器的攻击或命中事件，让武器攻击成为角色力量的表现载体。

接口协同必须遵守以下边界：

- 角色节点不能算作 A 级仙基、同参材料或一道 S 级神通；
- 角色路线终点不能与武器神通再次合并成共同上位等级；
- 角色来源武器附效不能写入或冒充武器先天词、后天附魔、`+强化`、命名进化、同参、神通、锻造或兵装共鸣；武器附魔可以按自身明确内容提供穿透或低伤害燃烧等局部补充（`ENCH-12`），但表现相似不改变二者的来源与职责；
- 角色可以影响武器获取或契合，但不能改写通用武器固定的神通谱；
- 专属武器可以更紧密地读取角色事件，但离开特定角色后仍要满足其报告中声明的基础运行规则；
- 角色来源武器附效由角色持有，动态作用于当前合法武器；
- 母路线不能以绑定具体武器实例或某类武器为成立前提，但允许武器与路线存在契合差异；
- 已确认的换装、手位、覆盖与触发边界见第 3.2 节；其他生命周期、标签／白名单和具体结算仍待确认，不能从角色持有效果推导出所有武器或所有攻击均合格；
- 角色主动使用有限携带槽且每个主动占一槽；具体槽数、扩展方式、与武器主动是否共用输入及输入优先级仍待确认。

### 3.2 角色附效与武器的协作规则

#### 3.2.1 普通换装、主副手切换与新武器启用

在变更前后均为该效果合法载体的前提下，普通换装以及主副手切换本身不清空角色侧已经完成的准备或临时进度，也不重置角色侧冷却（`CHAR-33`）。效果仍由角色持有；该规则不表示切到任一手位后都能触发，触发与消耗还须符合具体效果的手位和攻击条件。

新武器的主动技能需要很短的启用等待，普通攻击不受这段等待限制；该等待不覆盖武器固有冷却，也不改变副手不能释放正手主动的限制。等待时长、从何时起算、重新装备及命名进化等场景是否适用均待定，直接引用武器规则 `WPN-09`。武器拥有主动技能通常意味着较强的武器，只是设计方向，不构成任何品级门槛，见 `WPN-10`。

#### 3.2.2 已施加效果与暂时没有武器载体

普通换装本身不会清除或刷新已经施加的角色来源效果；它们按自身规则自然结束（`CHAR-34`）。该确认不决定伤害使用施加时快照还是后续动态读取。合法攻击再次施加同一效果的处理见 `CHAR-43`，其他归因和衍生伤害等结算仍待定。

若暂时没有武器载体，角色侧计时照常推进（`CHAR-35`）。这只确认计时，不确认无载体时能否触发、积累或消耗效果，也不表示游戏已允许丢弃最后一把武器或主动进入空手状态。

#### 3.2.3 手位由具体效果区分

用户指出的某些关键有限次数强化，例如只强化接下来几次攻击的关键效果，仅由当前主手触发并消耗；谁切到主手，就由谁按该效果的条件使用，副手不会代为触发或消耗。作为已讨论的例子，一段时间内持续附毒的效果可以由正副手触发（`CHAR-36`）。

这些规则与例子用于说明具体效果需要区分手位，不能扩写为“所有有限次数效果只准主手、所有持续效果都准双手”的固定二分法，也不能据此建立两种母路线模板。其他效果的手位范围仍须按其具体规则声明。

#### 3.2.4 适用条件、一次发动与强化覆盖

具体强化自身声明它适用于哪些技能或攻击。武器主动如果产生符合该强化条件的攻击，就可以触发；不能把所有武器主动统一视为合格，也不能因内容名为技能就排除其产生的合格攻击（`CHAR-37`）。具体标签、白名单、归因和衍生触发规则尚待讨论。

有限次数强化默认按一次符合条件的发动扣除一次；同一次发动中的多段命中不重复扣次（`CHAR-38`）。覆盖范围由具体强化定义，可以覆盖整次发动，也可以只覆盖指定部分（`CHAR-39`）。扣次单位与覆盖范围分别判断，不能因只扣一次就让所有攻击段或伤害段自动强化。

上述有限次数强化在符合条件的攻击出手时即消耗一次，挥空不返还，多段命中不额外扣次（`CHAR-40`）；不把扣次规则套用于所有附效。出手前取消或中断的边界，以及其余衍生结算仍待定。

#### 3.2.5 武器命中、状态持续伤害与再次施加

中毒与燃烧可以同时存在于同一目标；合法武器攻击可以分别按条件施加二者。但中毒的持续伤害不能给目标施加、叠加或刷新燃烧，燃烧的持续伤害也不能反向施加、叠加或刷新中毒（`CHAR-41`）。此条只确定这组状态持续伤害的边界，不代表全部衍生伤害或所有特例连锁的统一递归规则。

武器本身的范围攻击中，实际命中且符合附效条件的目标，都可以分别被施加附效；武器自身的穿透、弹射与分裂攻击同样按具体附效资格判断其实际命中（`CHAR-42`）。范围内未命中的目标不会仅因位于范围内便获得附效。该确认不设固定目标数或跳数，不授权所有衍生伤害无限递归，也不覆盖 `CHAR-39` 的强化覆盖定义。中毒、燃烧的状态持续伤害不能据此冒充武器原生攻击。

同一效果再次由合法攻击施加到同一目标时，刷新、叠层、独立持续或其他处理由具体效果声明，不设全局统一方式（`CHAR-43`）。具体层数、概率、时长及完整结算仍待定。

## 4. 术语

| 术语 | 当前定义 |
|---|---|
| 角色网络 | 某个角色独有的整张局内技能进化图 |
| 角色共核 | 同一角色全部母路线共同继承的主题、基础机制与不可被路线随意替换的底层规则 |
| 母路线 | 能够独立发展并抵达有效终点的一条主要成长方向 |
| 相关子节点 | 母路线内参与具体后继或跨路线融合关系的节点；不是统一层数、固定材料类型或预设子路线模板 |
| 融合路线 | 有关联的母路线通过各自相关子节点开辟、具有自身身份、战斗形态与后续成长的路线；与源母路线及其他路线保持区分度 |
| 路线闭环 | 一条母路线中，玩家的重复决策引发角色或战场变化，变化反馈并推动下一轮决策的完整战斗循环 |
| 局部规则 | 某条母路线为了形成闭环而引入的状态、对象或运行逻辑；不必是数值资源，也不必采用积攒—消耗 |
| 节点材料 | 用于构成路线闭环的主动、被动、效果组件和技能进化等内容；材料类别本身不是路线身份 |
| 力量载体 | 路线力量实际表现于直接技能、角色自身、武器攻击、召唤物或战场对象等位置的开放描述，不是固定路线类型 |
| 角色来源武器附效 | 从角色网络获得、由角色持有并动态作用于当前合法武器的角色效果；已确认的换装、手位、覆盖、触发与扣次边界见第 3.2 节，具体效果内容与其他生命周期仍待设计 |
| 路线投入 | 玩家在本局已经选择并生效于某条母路线的节点集合 |
| 深度前置 | 进入较深节点前必须满足的局部投入或状态条件；逐节点可以要求某一前置、多个条件同时满足或不同路径抵达，具体表达格式和门槛待定 |
| 路线终点 | 一条母路线自身能够完成的高阶结果，不依赖融合才有价值 |
| 融合关系 | 有关联的母路线通过各自相关子节点开辟融合路线的显式横向联系；不由标签自动生成，不固定参与路线数量 |
| 普通等级窗口 | 每次普通升级选择角色基础属性的窗口，不直接替代角色技能节点 |
| 经验里程碑 | 同一条普通经验进度上的配置节点；触发额外角色窗口，不是第二条经验条 |
| 常规角色机会 | 由经验里程碑稳定打开的角色节点选择窗口；稳定的是窗口，不是特定节点 |
| 稀有角色机会 | 由精英、Boss、剧情或特殊机缘提供的高阶角色窗口 |
| 行为条件 | 从本局打怪或战斗行为记录计算的节点资格条件，不是可消费资源 |
| 特殊机缘 | 特定遭遇、事件或掉落提供的稀有资格、候选或直接获得入口 |
| 候选资格 | 节点已经通过内容解锁、结构前置、行为条件和来源限制，可以参加相应抽取 |
| 候选出现 | 一个具有资格的节点实际被抽中并展示给玩家；不等于已经获得 |
| 节点获得 | 玩家选择或明确的直接获得机缘授予节点结果；新角色主动的获得不等于已经携带，多级节点可提供升级已有能力的结果 |
| 分层公开 | 根据信息的重要性，分别采用完整公开、线索公开后发现转完整、或极少数完全隐藏 |
| 发现记录 | 玩家首次有效发现内容后写入图鉴的永久知识状态，不是战斗成长或内容自动解锁 |
| 进入路线 | 建立该母路线核心机制与基本操作问题的共同语义阶段 |
| 深化塑形 | 扩展、分化或强化核心机制，使路线形成具体发展形状的共同语义阶段 |
| 机制质变 | 让路线的运作方式发生显著变化，而不只是提高数字的共同语义阶段 |
| 路线终点 | 完成该母路线独立高阶表达的共同语义阶段；没有融合也必须成立 |
| 路线身份契约 | 在制作节点前描述一条母路线如何连接角色共核、形成闭环，并定义注意对象、空间、成长、局部规则、力量载体、质变与终点的设计记录 |
| 节点内容种类 | 节点作用的角色内容是什么，例如主动技能、被动技能或效果组件 |
| 节点操作 | 节点如何作用于内容，至少能表达新授予、新增效果和进化既有技能；进化方式逐技能／节点设计，不设封闭操作枚举 |
| 主动技能内容 | 需要玩家主动触发的角色能力；已获得与当前携带分开，使用有限携带槽，每个主动占一槽，具体槽数与输入仍待定 |
| 单级节点 | 只有一个等级的角色节点；多数节点采用此形式，获得后退出候选 |
| 多级节点 | 部分明确设计的关键节点可再次提供升级已有能力的选择；具体等级数量、成长内容与完整候选规则待定 |
| 当前携带 | 玩家当前选择放入有限角色主动槽的能力；已获原版与上位版默认可各占一槽共携，显式局部冲突可互斥，不等于自动携带所有已获主动 |
| 节点改选 | 特殊机缘允许的本局已选节点调整；默认从重新生成的合法随机候选中改选，范围、返还和后继依赖等仍待定 |
| 重抽机会／道具 | 某些机缘提供、可在本局留存供以后使用的重抽能力；骰子是例子，不通过放弃选择获得，具体名称、次数与持有规则待定 |
| 整组重抽 | 使用重抽机会重新生成整组已展示候选；从当前实际合法池抽取，优先避开紧接着的上一组，池不足时允许重复 |
| 被动技能内容 | 持续或条件生效的角色机制，不要求独立主动输入 |
| 效果组件 | 可以附着于角色、技能、姿态、资源状态或既有行为的独立效果定义 |
| 新授予操作 | 让此前未获得的主动、被动或其他合法角色内容进入本局构筑 |
| 新增效果操作 | 为角色或已存在内容附加新的效果／事件响应，但不自动替换原能力 |
| 技能进化操作 | 以已获得技能为目标，按具体技能与节点设计其变化；增强、变形、替换等是可用操作，不是统一模板或封闭枚举 |
| 合法候选池 | 在当前角色、本局解锁状态、局部前置和其他已确认条件下可以被抽取的节点集合 |
| 候选组 | 一次成长窗口中从合法候选池随机呈现给玩家的有限选项；数量尚未确认 |
| 开放式投资 | 不设全局主／副路线槽位，也不以中期承诺关闭其他母路线的结构 |

母路线的四种共同语义阶段与最低节点结果形式已经确认。技能进化按具体技能／节点独立设计，可采用增强、变形、替换等操作；这些例子不构成封闭枚举，也不禁止复用节点材料。融合路线是否采用母路线的四阶段尚未确认。

## 5. 已确认的网络拓扑

### 5.1 独立角色网络

- 每个角色有自己的网络定义和稳定 ID 空间。
- 不同角色不共享同一组母路线；相似主题也必须根据各自身份重新定义。
- 母路线数量是逐角色配置，不存在全局固定五条的要求。
- 每条正式母路线都能独立抵达一个可用终点。

### 5.2 开放式多路线投资

局内不设置“主路线槽”“副路线槽”或“最多进入两条母路线”等全局限制，也不要求玩家在中期宣誓或锁定唯一主路线。

一次角色成长机会生成候选时，候选资格按节点自身条件判断，而不是按“是否属于已选主路线”判断。因此：

- 投资路线 A 不会仅因全局路线锁而关闭路线 B；
- 玩家此前没有投资某条路线，不代表后续永远不能进入它；
- 满足局部前置的不同路线节点可以同时存在于合法候选池；
- 玩家可以从专精转向广度，也可以停止扩展并继续深化已有路线；
- 系统不会保证任一特定合法节点在某次或某局必然出现。

开放式投资禁止的是**全局路线名额限制**。兼容节点可以共同取得，有冲突的方向按节点组显式配置局部互斥；不统一要求所有方向共存或互斥。局部互斥及具体采用的一次性取舍或剧情选择必须明确配置并在选择前披露，不能把它们扩大成整条母路线锁，更不能退化为整张网络的主／副路线锁（`CHAR-45`）。

### 5.3 广度与深度的成本

开放式投资通过机会预算和深度前置形成自然成本：

- **广度成本**：在更多路线中选择节点，会占用同一局有限的角色成长机会；
- **深度成本**：高阶节点和路线终点需要满足该路线的局部前置，不能从零投入直接跳到终点；
- **随机成本**：合法不等于必得，玩家可能需要根据实际候选调整计划；
- **无硬锁补偿**：系统不再额外用路线槽或中期锁定惩罚跨路线尝试。

具体机会数量、深度层数、前置门槛与表达格式和随机权重仍待关卡节奏与节点语法共同确定；前置的逐节点组合或替代关系见第 5.10 节。

### 5.4 相关子节点开辟有自身身份的融合路线

- 只有主题、机制或战斗场景确实相近的路线才配置融合关系。
- 没有融合关系的路线可以并行发展，不会因此成为错误搭配。
- 每条母路线在没有融合时仍须成立，融合不能成为修复废路线的隐藏配方。
- 有关联的母路线通过各自相关子节点形成显式横向联系，开辟融合路线；融合路线本身具有后续成长、自己的战斗形态与路线身份，并与源母路线和其他路线保持区分度（`CHAR-50`）。
- 融合不要求所有路线两两连接，也不把两个来源的例子写成参与路线数上限。不能用一个孤立的机制结果替代融合路线。
- 融合入口及后续节点与其他角色节点采用相同成长选择方式，满足自身前置与来源条件即可进入相应合法池，也允许出现在常规角色窗口；确有特殊来源要求的节点仍遵守自己的限制（`CHAR-51`）。融合的分层公开规则不因此改变。
- 默认不会因为出现融合资格就自动删除原路线投入。具体入口条件、融合后的源技能处理、后续节点结构与可逆性仍待定；不得把“拥有后续成长”扩写成固定节点数量或母路线四阶段。

### 5.5 共源分窗与特殊资格

角色成长使用一条普通经验进度，但产生两种相互独立的窗口：

- 普通等级窗口稳定负责基础属性；
- 配置的经验里程碑在普通等级之外，额外打开常规角色机会。

获得常规角色机会不会吃掉该等级原本的基础属性选择。精英、Boss、剧情和特殊机缘承担稀有突破、融合或其他重大角色结果，作为常规里程碑骨架的补充，而不是完全取代稳定成长。该分工不把全部融合入口限定在特殊机缘：按 `CHAR-51`，合格融合入口及后续节点也可以进入常规角色窗口。

部分节点还可以拥有局内行为条件或来源限制。系统必须为每个这类节点明确声明满足条件后的结果：

1. 只解除候选资格，随后仍需经过随机抽取；
2. 由该机缘形成专属候选，但仍由玩家确认选择；
3. 由明确的直接获得机缘立即授予。

三种结果不能混写。“达成击杀行为”默认不会被实现层擅自解释成“自动学会技能”；节点内容必须显式选择上述获得方式。行为计数只属于本局运行状态，不形成第二条角色经验、可消费碎片或局外永久数值。

### 5.6 四种共同语义阶段

每条母路线都必须依次完成：

```text
进入路线 → 深化塑形 → 机制质变 → 路线终点
```

这四项定义的是成长职责，不是统一模板。它们不规定每个阶段有几个节点、是否出现分枝、路线总长度、获得窗口或具体图形。具体路线通过角色共核、闭环和身份契约接受差异审查；节点数量、连接方式与实际内容继续逐角色设计，不能复制同一条四节点直线后只替换效果名称。

融合路线也必须具有自己的身份、战斗形态和后续成长，但是否采用上述四阶段尚未确认，不能自动沿用母路线的阶段或节点数量。

### 5.7 角色共核与路线闭环

角色网络先定义一份所有母路线共同引用的角色共核。共核说明角色共同主题、基础战斗语言及不能被单一路线任意替换的底层规则；它负责让跨路线构筑仍然属于同一个角色，但不能把所有路线压成同一种循环。

每条母路线再围绕共核形成自己的完整闭环：玩家反复作出某类决策，引发角色或战场状态变化，该变化产生可观察反馈并推动下一轮决策。闭环可以依靠技能、角色状态、战场对象、武器攻击附效或其他载体，也可以使用局部规则；它不必拥有独立资源条，也不必遵循统一的积攒—消耗顺序。

完整闭环是路线审核要求，不是要求所有路线按“输入—积攒—消耗—结算”填写同一模板。作者应使用最能解释该路线实际玩法的语言描述它。

### 5.8 路线身份契约

每条母路线在进入节点制作前必须声明：

1. **共核联系**：它怎样表达该角色共同主题和底层规则，而不是成为另一个职业。
2. **核心闭环**：玩家反复作出什么决策，角色／战场如何变化并反馈；若存在代价、风险或资源，再明确说明。
3. **注意对象**：玩家主要持续观察和操控什么；即使注意对象与同角色其他路线重叠，也要说明核心决策与反馈的差异。
4. **空间命题**：路线如何改变距离、移动、站位、方向或区域控制。
5. **成长形状**：四阶段通过直线、分枝、并行组件、汇聚、条件觉醒或其他手工图形完成。
6. **获得节奏**：主要由常规里程碑深化，还是包含行为条件、稀有突破或剧情机缘。
7. **局部规则与力量载体**：需要哪些局部状态／规则，力量表现于哪些开放载体；不默认新资源条或固定三类模板。
8. **机制质变**：中后期究竟改变哪项运行方式，而不只是增加数值。
9. **终点表达**：最终操作循环、角色状态和屏幕形态是什么。

这些字段是设计审查问题，不是有限的路线模板库。不同路线可以偶尔采用相似形状，但不能同时复制核心循环、空间命题和终点表达。若三者在替换包装后仍可互换，这两条路线必须合并或重做。

### 5.9 语义阶段与节点结果正交

四种阶段描述节点处于成长弧线中的职责；节点内容种类描述作用对象；节点操作描述如何改变对象。它们不能绑成固定对应关系。

当前确认系统至少能够表达以下玩家可见结果：

- 新授予主动技能；
- 新授予被动技能；
- 为角色或既有行为新增效果；
- 进化此前已经获得的技能。

这四种结果是构成路线闭环的材料，不是四种母路线。召唤、姿态、资源规则、角色来源武器附效等机制领域通常仍由主动、被动或效果组件表达；只有现有内容种类确实无法准确承载时，才扩展 `content_kind` 并明确新旧边界。技能进化操作必须引用一个已经获得的目标技能，其增强、变形、替换等方式按具体技能与节点独立设计，不设统一模板或封闭枚举（`CHAR-44`）。这种独立设计不禁止复用材料，也不废除角色共核与母路线闭环要求。

### 5.10 逐节点前置与局部兼容

每个节点自行定义前置满足方式：可以要求某一前置、多个条件同时满足，或允许不同路径抵达；不规定全局前置数量、深度或融合门槛（`CHAR-49`）。候选判断按节点实际条件执行，不从“母路线／分枝／融合”名称推断固定配方。

兼容节点允许共同取得，冲突方向逐节点组明确局部互斥（`CHAR-45`）。该分组描述内容兼容关系，不是候选抽取配额，也不是已获确认的成组改选单位。

### 5.11 节点等级与后继并行

多数角色节点只有一个等级，获得后退出候选。部分明确设计的关键节点可以多级成长，再次提供升级已有能力的选择（`CHAR-52`）。新主动技能节点是一种例子，不表示所有主动都必须多级，也不表示只有主动才能多级；具体等级数量、成长内容／数值和完整等级候选规则尚未确定。

等级提升与后继分枝可以并行，不统一要求原技能满级后才能进化；具体后继仍可设置等级前置（`CHAR-53`）。玩家可以依据实际候选选择继续升级或取得后继，但这不保证升级与后继在同一窗口同时出现。

### 5.12 角色主动的获得、携带与更换

获得新角色主动或可供替换的上位版本后，由玩家选择携带内容，不自动强制替换当前携带技能；“已经获得”与“当前携带”必须分开（`CHAR-54`）。已获得的原版与上位版默认可以共同携带，各占一个槽；只有明确配置的局部冲突才构成相应互斥例外，不能仅因属于原版／上位版就禁止共携（`CHAR-57`）。这一确认不代表所有版本自动永久存入长期版本库，也不决定等级转移、生命周期或输入。

角色主动使用有限携带槽，每个主动占一个槽，不按强度占不同槽数（`CHAR-55`）。具体槽数、扩展方式、角色差异、是否与武器主动共用输入等仍待定；携带槽不限制母路线投资名额。

只在指定的调整时机更换携带的角色主动，不能局内随时更换（`CHAR-56`）。具体允许窗口尚未确定，“获得新主动后的配置环节”只是此前举出的候选时机。更换携带时的冷却、既有效果、输入、UI 和存档规则仍待定，不自动套用武器换装规则。

## 6. 局内主流程（当前可确认部分）

```text
进入角色个人关卡
        ↓
载入该角色已在局外解锁的网络内容
        ↓
战斗、击杀并拾取普通经验
        ↓
普通等级窗口：选择一次基础属性
        ↓
若到达配置的经验里程碑
        └─ 额外打开常规角色机会

与此同时：精英／Boss／剧情／特殊机缘
        └─ 可打开稀有角色机会、形成专属候选或提供声明的直接获得
        ↓
按内容解锁、节点前置、局部互斥、局内行为条件和来源限制过滤
        ↓
按节点声明的获得方式分流
├─ 进入随机池：汇集相应窗口的实际合法节点，含合格母路线及融合路线节点
│    └─ 直接随机抽取有限具体候选 → 玩家选择，无需预选路线或类别配额
│       常规节点窗口不提供放弃，可按第 6.2 节使用重抽机会后再选择
├─ 专属候选：相应机缘形成专属候选 → 玩家确认选择
└─ 直接获得：由已声明的直接获得机缘授予
        ↓
三种方式均在实际获得后进入以下结算
        ↓
获得节点或提升已有能力等级，记录路线投入并重新计算后继／融合资格
        ↓
继续战斗；后续仍可升级、选择后继或进入其他合格路线
        ↓
在标准局形成至少一个清晰的高阶角色构筑结果
        ↓
通关、失败或进入无尽
```

多数单级节点取得后退出候选；明确设计的多级节点可再次提供升级选择，后继资格按节点自身前置判断。新角色主动的获得与当前携带分别处理，不在上述获得结算中自动强制替换携带技能；只有指定调整时机才允许更换，具体窗口仍待定。

融合入口及后续节点可以按自身条件进入常规窗口，专属候选与直接获得仍走各自声明来源。常规角色节点不放弃及整组重抽的基本规则已确认，不能推广为所有特殊入口的处理。具体里程碑、每局次数、候选数量、权重、重抽的次数与不足池重叠细则、无合法候选处理和完整等级候选规则仍待定。

### 6.1 特殊机缘中的节点调整

玩家可以通过特殊机缘调整本局已经选择的角色节点，并非随时自由洗点或改选（`CHAR-46`）。这类调整默认重新生成合法随机候选供玩家改选，候选仍须满足解锁、前置与来源限制（`CHAR-47`）。

具体机缘来源、代价、调整范围、返还、后继依赖、融合后源技能处理及其他可逆性仍待确认。此前助手提出的“按依赖关联成组调整”没有获得用户选择，不能从局部互斥的节点组概念推导出成组调整机制。

### 6.2 常规角色节点选择与留存重抽

常规角色节点选择窗口不提供放弃（`CHAR-58`）。用户提出“如果以后设计放弃则应有补偿”是条件性意见，没有启用放弃，也没有确定补偿。武器命名进化的放弃及 `+1` 补偿由武器规则独立负责，不能移植到常规角色节点窗口。

某些机缘可以提供重抽机会或道具，骰子是已讨论的例子；它可以保留在本局中，留待以后使用，不通过放弃一次选择获得（`GROW-09`）。具体名称、来源、数量、使用次数、持有上限、成本及存放方式仍待定；未确认跨局保留。

使用重抽时，重新生成当前展示的整组候选，不是指定其中一项重抽。新候选来自当前实际合法池，仍遵守解锁、前置与来源限制（`GROW-10`）。重抽优先避开紧接着的上一组候选，合法池不足时允许重复；不累计排除全部历史候选，也不保证目标节点、等权或更强的新内容保底（`GROW-11`）。

```text
常规角色节点窗口展示有限具体候选
├─ 直接选择其中一项 → 按节点规则获得或升级
└─ 使用可用重抽机会 → 从当前实际合法池重新抽取整组
                         优先避开上一组；合法池不足时允许重复
                         → 从重抽后的候选中选择
本窗口不提供放弃；单窗口可重抽几次及无合法候选时如何处理仍待定
```

同一重抽机会可以用于普通属性选择、角色节点选择、武器命名进化候选选择和常规附魔候选选择（`GROW-13`）。`GROW-12` 保留此前三类用途的历史记录，现已由 `GROW-13` 扩展替代。常规附魔同样按 `GROW-10/11` 整组重抽，遵守实际合法目标与来源筛选；本报告落实已讨论的常规角色节点窗口，不据此把所有特殊、专属或直接授予入口都改成可重抽，也不把重抽候选扩大为重洗武器先天词、所有随机字段或商店货架。特殊直接授予附魔尚未确认可重抽。武器只有一至两条合法进化方向时重抽的实际效果与成本等细节由 `GROW-Q01` 继续追踪，常规附魔候选不足尤其整个合法池为空的处理由 `ENCH-Q04` 关联追踪。

## 7. 随机候选的不变量

需要随机选择的窗口已确认采用先筛合法节点、再直接随机抽取有限具体候选的方式（`CHAR-48`）；重抽按 GROW-10/11 处理，权重及其余重复细则仍待定。该方式必须满足：

1. 先按解锁、节点前置、局部互斥、行为条件与来源约束筛出实际合法节点，再直接从池中随机提供有限具体候选，不展示未解锁或条件不合法的选项。
2. 合法池横跨全部可进入母路线及合格融合路线节点，不能因为玩家先点了某条路线就默认屏蔽其他路线；不先选／锁母路线，也不按类别分组配额。
3. 随机性必须真实影响构筑，不能暗中保证玩家预定路线完整出现。
4. 每个候选被独立选择时都应有可用价值，不能只作为等待隐藏融合的空白材料。
5. 候选数量不是全局固定的“三选一”；常规、精英、Boss、剧情等窗口是否使用不同数量仍待确认。
6. 重抽优先避开紧接着的上一组，合法池不足时允许重复；更广的候选污染、重叠处理与其他重复策略仍须结合节点语法和机会预算设计，不能自行增加历史累计排除或更强保底。
7. 经验里程碑只稳定保证常规角色窗口出现，不保证某条路线或某个节点出现。
8. 局外内容解锁、局内候选资格、候选实际出现和节点获得是四个不同状态。
9. 行为条件或特殊机缘的结果必须显式声明为“进入随机池”“形成专属候选”或“直接获得”。
10. 各节点前置可以表达指定前置、多条件同时满足或不同路径抵达，不固定全局数量、深度或融合门槛。
11. 获得节点后重新判断后继与融合资格，但不保证后继出现在下一次窗口。
12. 多数单级节点取得后退出候选；部分关键节点可继续提供等级提升。升级与后继可以并行满足资格，不要求所有技能先满级，也不保证两者同窗出现。
13. 融合入口和后续节点可以进入常规角色窗口；逐节点特殊来源仍有效，不能把全部融合入口改成特殊机缘专属。
14. 常规角色节点窗口不提供放弃；可使用符合规则的重抽机会整组重抽，不将角色节点改选、武器放弃或特殊来源流程混为同一种操作。
15. 重抽始终基于当前实际合法池，不能通过重抽绕过解锁、前置、局部互斥、行为条件或来源限制。

“直接从合法池随机”不等于已经确认等权、固定候选数或目标保底；已确认的紧邻上一组回避不代表其余重复策略已经完成，也不声称已核实任何参考游戏的内部算法。

## 8. 标准局与无尽模式

### 8.1 标准局

标准局以经验里程碑提供稳定的常规角色成长骨架，再由精英、Boss、剧情和特殊机缘提供稀有变化。符合条件的融合入口及后续节点也可以进入常规角色窗口。标准局应让玩家有机会形成至少一个清晰的角色高阶结果，但不承诺点满整张网络，也不承诺触发每个条件节点。选择广度意味着可能放弃单路线终点速度；选择深度意味着减少横向适应和融合机会。标准局中的实际里程碑、可获得节点数、可完成路线数与融合密度尚未确认。

### 8.2 无尽模式

无尽可以继续提供角色成长机会，使玩家探索更多母路线和明确存在的融合关系，但不能让网络无限产生无意义的小数值节点。角色网络在无尽中的上限需要与多神通 S、锻造、敌人强度和屏幕可读性共同设计。

无尽中的更多投入不转化为局外永久数值；下一局仍需重新构筑。

## 9. 局外解锁的作用

高难度、角色故事、挑战和其他横向进度可以解锁：

- 新母路线；
- 某条路线的新节点或分枝；
- 已明确设计的融合关系；
- 新的角色主动、表现、剧情与挑战条件。

解锁只让内容进入未来局内的可用集合，不会直接替玩家激活节点，也不会永久增加伤害、生命等数值。随着内容池扩大，如何控制候选污染和解锁后稀释需要单独设计，当前尚未确认。

## 10. 信息披露、发现与 UI 要求

### 10.1 三层公开规则

| 层级 | 适用内容 | 初次显示 | 首次发现后 |
|---|---|---|---|
| 完整公开 | 常规母路线、普通行为条件 | 显示具体要求与本局进度 | 持续完整显示 |
| 线索公开 | 稀有节点、角色融合、特殊来源 | 至少显示来源类别或可理解的剧情线索 | 图鉴永久公开完整条件 |
| 完全隐藏 | 极少数非核心彩蛋 | 不承诺预先提示 | 发现后可以登记完整信息 |

核心路线终点、构筑必需节点，以及完成 S 神通谱所需的重要 A 不能使用“完全隐藏”。分层公开的目的，是保留发现感而不迫使玩家依赖外部攻略。

图鉴保存的是玩家已经取得的知识。它不能替代局外内容解锁，不能使节点开局生效，不能提高候选权重，也不能给角色或武器增加永久数值。

首次有效发现究竟以“条件触发、候选首次出现还是首次获得”为记录时点，仍需在图鉴与存档设计阶段为每类内容明确配置。

### 10.2 选择界面

未来选择界面至少需要让玩家在确认前理解：

- 候选属于哪名角色、哪条母路线或融合路线；
- 当前已投入的路线与节点；
- 候选是开路线、深化路线、路线终点还是融合相关内容；
- 已知的前置、局部互斥、代价和不可逆结果；
- 本次窗口来自普通里程碑还是精英、Boss、剧情或特殊机缘；
- 条件节点当前处于内容未解锁、行为条件未满足、已有资格、已经出现或已经获得中的哪一状态；
- 满足条件后是进入随机池、形成专属候选还是直接获得；
- 当前公开层级，以及尚未发现内容所提供的来源／剧情线索；
- 该选择如何改变角色行为，而不只显示数值；
- 该节点是否让技能、角色自身、武器攻击或其他对象承载力量，以及效果仍属于哪个成长系统；
- 某条融合关系是公开、待发现还是尚未解锁。

UI 不应要求玩家先把某路线标成“主路线”才能选择其节点。网络总览可以帮助规划，但不能承诺随机候选一定按总览顺序出现。

已确认的概念还须区分节点首次获得与等级提升、角色主动已经获得与当前携带。已获原版与上位版默认可以各占一个槽共同携带；只有显式局部冲突才构成相应互斥。具体携带调整窗口、输入与 UI 布局均待后续设计。

常规角色节点窗口不提供放弃入口；使用重抽时替换整组候选，不表现成选择一项单独刷新。重抽机会可以在本局留存，且可服务于 GROW-13 的四类已确认用途；显示概念须与节点改选及武器放弃补偿区分。具体物品名称、次数、持有上限、存放方式、退出／撤销／返还及空池处理仍待定，不能在界面中补成默认规则，也不能把此处要求推广至所有特殊节点窗口。

母路线引入局部规则时，应优先通过战场对象、角色动画、状态标记、技能反馈和必要的短时提示表达。只有玩家必须持续读取一个独立量才能作出路线核心决策时，才新增专用 HUD 条；不能默认一条母路线对应一根资源条。

### 11.4 融合关系定义

融合关系独立于语义阶段、内容种类和节点操作。以下是既有最低字段草案：

- `fusion_relation_id`
- `source_route_ids`
- `result_node_id`

`CHAR-50` 已确认相关母路线通过各自子节点开辟融合路线，结果具有自己的身份和后续成长。上述 `result_node_id` 不能被解释为“融合仅产生无后继的单点结果”；来源子节点、融合入口、路线身份与后续成长如何完整映射到数据仍待设计，本批不新增字段。

## 13. 验证不变量

未来原型和测试至少应能验证：

- 选择路线 A 的普通节点后，路线 B 不会仅因“已选主路线”而从合法池永久消失。
- 同时投资多条路线不会触发隐藏的路线数量上限。
- 玩家选择广度时消耗真实成长机会，不能无成本收集所有浅层节点。
- 深层节点不会在局部前置未满足时进入合法池。
- 每条母路线在完全没有融合的情况下仍能形成可用终点构筑。
- 未配置融合关系的两条路线能够并行运行，但不会自动生成融合效果。
- 角色节点不会修改武器品级、生成武器神通或替代同参材料。
- 局外解锁不会让节点在开局自动生效，也不会带入永久基础数值。
- 普通等级始终结算基础属性；命中角色里程碑时另开窗口，不互相吞掉奖励。
- 精英、Boss、剧情和特殊机缘可以提供稀有角色机会，但不会让稳定里程碑骨架失效。
- 未满足局内行为条件的节点不能进入对应合法池；满足后也只执行该节点声明的获得方式。
- 进入随机池、形成专属候选和直接获得分别执行：专属候选不被改为跨路线随机抽取，直接获得不额外经过候选抽取或玩家选择。
- 行为计数不会出现在局外永久数值或可消费资源中。
- 常规行为条件在 UI 中能显示准确要求和实时进度。
- 稀有内容初次至少能给出有效线索；首次发现后，图鉴能显示完整条件。
- 标记为核心终点、构筑必需或重要同参 A 的内容不能配置为完全隐藏。
- 写入发现记录前后，同一种子和本局状态下的候选资格、随机权重与战斗数值保持不变。
- 每条正式母路线都能识别出进入、深化、质变和终点四种阶段职责。
- 内容数据不会据此强制所有路线拥有相同节点数、分枝数或图形。
- 每条母路线在加入节点池前都具有完整路线身份契约。
- 同一角色的路线经过包装剥离后，核心循环、空间命题与终点表达不能整体互换。
- 普通母路线节点分别声明语义阶段、内容种类与操作；候选系统不会从阶段自动猜测节点结果。融合路线是否采用母路线四阶段仍待定，不据此强制套用。
- 采用技能进化操作的节点引用已经获得的目标技能，不会在缺少目标时进入合法候选池。
- 融合关系由独立对象显式声明，不会从节点操作或路线标签自动生成。
- 同一角色的所有母路线都能追溯到同一角色共核，同时不会把共核复制成同一个战斗闭环。
- 剥离名称、VFX、伤害类型、节点材料比例与力量载体标签后，同角色的正式母路线仍具有不同的核心决策和状态反馈。
- 注意对象重叠不会单独导致路线审核失败；审核仍须检查核心决策与状态反馈的差异。
- 系统允许不新增数值资源条、也不采用积攒—消耗的母路线形成完整闭环；HUD 条数量不会随母路线数量机械增长。
- 角色来源武器附效保持角色网络来源标识，不会写入或冒充武器的先天词、附魔、`+`、谱系、同参、神通、锻造或兵装共鸣。
- 角色来源武器附效的运行时所有权属于角色，并动态作用于当前合法武器；仅按已确认的生命周期与适用条件验证，不能预设所有武器或所有攻击均触发。
- 每条母路线的成立不依赖绑定具体武器实例或某类武器；武器与路线可以存在契合差异，不能据此要求所有武器具有相同协同表现。
- 在前后均为合法载体时，普通换装及主副手切换不清空角色侧准备／临时进度，不重置角色侧冷却；角色侧状态保留不自动赋予新手位触发资格。
- 新武器主动受启用等待约束，普通攻击不被这段等待封锁；等待不覆盖固有冷却或副手限制。具体时长、起算点和重新装备／进化适用性未确认前，不擅定数值或场景预期。
- 已经施加的角色来源效果不会因普通换装被清除或刷新，而按自身规则结束；该验证不预设伤害快照或动态读取方式。
- 暂时无武器载体时角色侧计时照常，不借此授予无载体触发、积累、消耗或丢弃最后武器的能力。
- 仅当前主手可用的关键有限次数强化不会由副手触发或消耗；持续附毒的已讨论例子可以由正副手触发。其他效果不因有限次数或持续时间标签自动继承这两种手位配置。
- 强化按自身声明筛选技能／攻击；武器主动产生合格攻击时可以触发，不合格主动不会仅凭“主动技能”身份获得资格。
- 同一次符合条件的发动默认只扣一次有限强化次数，多段命中不重复扣；覆盖按具体强化定义为整次或指定部分，不从扣次单位推导全段强化。
- 本轮有限次数强化在合格攻击出手时即消耗，挥空不返还；出手前取消或中断以及其他附效是否涉及次数，不由此测试擅定。
- 同一目标可以同时处于中毒与燃烧状态，但任一状态的持续伤害不会施加、叠加或刷新另一状态；不把此检查扩写成全部衍生伤害的统一递归方案。
- 武器范围攻击中实际命中且符合条件的目标可分别获得附效；未命中的范围内目标不因此自动附效。武器自身穿透、弹射、分裂仍按具体附效资格与强化覆盖判断，不能因传播形态就断言所有段合格。
- 同一效果被合法攻击再次施加到同一目标时执行自身声明的刷新、叠层或独立持续等处理，不采用未确认的全局规则、层数、概率或时长。
- 具体技能与节点能独立声明进化方式，不被统一增强／变形／替换模板限制，也不因独立设计而禁止复用材料或绕开共核与闭环要求。
- 兼容节点可以共存，冲突方向的互斥逐节点组明确；局部互斥不会变成整条母路线锁或候选类别配额。
- 节点改选须有特殊机缘，默认提供重新生成的合法随机候选；未确认的代价、返还、范围与后继依赖处理不得被测试定案，尤其不默认按依赖成组调整。
- 随机成长窗口先筛实际合法节点再直接抽取有限具体候选，不要求预选路线，也不保证后继、融合或任何候选类别出现；专属候选与直接获得保持来源分流。
- 节点前置分别支持所声明的指定前置、多个条件同时满足或不同路径抵达，不从路线名称推断固定前置数量或深度。
- 融合由关联母路线各自相关子节点开辟，其路线具有可区分的身份、战斗形态与后续成长；不能用孤立联动效果通过融合路线审查，也不强制固定四阶段或参与路线数。
- 合格融合入口及后续节点可以进入常规角色窗口；只对确有特殊来源的节点施加相应限制，且分层公开不会因进入常规池而被改写。
- 多数单级节点获得后退出候选；多级关键节点可提供升级，不能把所有主动固定为多级或排除其他可多级内容。具体等级数与完整候选处理仍按后续确认验证。
- 升级与后继分枝可以同时具有资格，后继按自身等级前置判断；不要求全部满级，也不保证二者同窗出现。
- 获得新角色主动或可替换的上位版本不自动覆盖当前携带；已经获得与当前携带分别处理。原版与上位版默认可各占一槽共携，显式局部冲突除外；不从共携推导长期版本库或等级转移。
- 角色主动每个占一个有限携带槽，不按强度多占槽，不限制母路线投资；槽数、扩展、角色差异与武器输入关系仍待定。
- 只有指定调整时机才可更换携带角色主动；具体允许窗口、冷却和既有效果处理未确认前，不采用随时切换、自动开启配置环节或沿用武器换装规则的测试预期。
- 原版／上位版身份本身不会被判为互斥；只有已声明的局部冲突才阻止相应组合，携带槽数量和输入规则不能由共携结论擅定。
- 常规角色节点选择不提供放弃，也不通过放弃发放补偿或重抽道具；不把此限制推导为武器命名进化不能放弃，或所有特殊节点窗口都采用相同流程。
- 重抽机会可在本局留存供以后使用，但测试不预设具体名称、次数、持有上限、来源预算、成本或跨局保留。
- 使用重抽机会后整组候选重新生成，仍来自当前实际合法池；不能只替换玩家点选的一项，也不能绕过解锁、前置、局部互斥、行为或来源限制。
- 重抽优先避开紧接着的上一组，合法池不足允许重复；不累计排除更早候选，也不产生目标保底、等权或其他更强保证。
- 同一重抽机会可用于普通属性、角色节点、武器命名进化与常规附魔候选四类选择（GROW-13）；常规附魔候选遵守目标资格与来源限制，不自动扩展为重抽特殊直接授予附魔、重洗先天词、其他随机字段或商店货架。
- 只一至两条合法武器方向时的重抽效果／成本、池不足的重叠细则、退出／撤销／返还以及空池处理尚未确认，不在角色测试中补全。

## 14. 待定问题与讨论顺序

### 14.1 已解决：角色成长机会来源

采用共源分窗混合制：普通经验等级负责基础属性，配置里程碑额外提供常规角色窗口；精英、Boss、剧情和特殊机缘负责稀有补充。具体时间、次数和预算仍由未来关卡报告确定。

### 14.2 已解决：特殊条件的信息透明度

采用分层公开：常规条件完整显示；稀有节点、融合和特殊 A 先给线索，首次发现后永久公开；极少数非核心彩蛋可完全隐藏。图鉴只保存知识。

### 14.3 已解决：母路线共同阶段

每条母路线共享进入、深化、质变和终点四种语义阶段，但节点数量、分枝和图形不固定。

### 14.4 已解决：路线身份与流程差异

采用扩展路线身份契约，并以剥离包装后的角色共核联系、完整闭环、核心决策、空间命题和终点表达进行同角色重复检查。共同阶段不规定具体成长形状。

### 14.5 已确认：最低节点结果形式

角色网络至少支持新主动、新被动、新增效果和进化既有技能；语义阶段、内容种类与操作正交，且未来可以增加边界明确的新种类。

### 14.6 已确认：角色共核、局部规则与开放力量载体

同一角色路线共享角色共核，但每条路线形成不同完整闭环。路线可以拥有非资源型局部规则，力量可以表现为直接技能、自身强化、角色来源武器附效或其他符合主题的载体；节点材料和力量载体都不是固定路线分类。

### 14.7 角色附效：覆盖与出手扣次已解决，其余边界继续分项确认

角色来源武器附效由角色持有，母路线不绑定具体实例或某类武器。`CHAR-33` 至 `CHAR-43` 已确认部分换装、计时、手位、攻击条件、强化覆盖、出手扣次、状态持续伤害与重施处理边界；它们没有解决完整生命周期与结算，也没有把全部角色效果固定分成两类。

- **CHAR-Q09｜部分解决**：所有权、合法载体间普通换装／主副手切换的角色侧准备与冷却、普通换装后的已施加效果以及暂时无载体时的计时已确认；命名进化、A→S、丢弃及不符合效果条件的装备变化等其余生命周期、既有效果的伤害快照与状态结算仍待定。
- **CHAR-Q10｜部分解决**：具体效果区分手位、强化声明适用技能／攻击、武器主动产生合格攻击时可触发，以及 CHAR-41～43 的状态持续伤害、合法武器命中与同效重施方式已确认；其余手位配置、标签／白名单、候选资格、强度、尚未涵盖的衍生伤害／残留／归因／递归、UI 与存档仍待定。
- **CHAR-Q11｜已解决**：同次强化覆盖由具体效果定义（CHAR-39）；本轮有限次数强化在合格攻击出手时消耗，挥空不返还（CHAR-40）。出手前取消／中断与其余结算另待定，不因该问题已解决就补全。

武器启用等待的数值与场景细则仍由 `WPN-Q03` 追踪；本批没有追加武器换装、命名进化或 A→S 的生命周期规则。

### 14.8 节点进化、融合与主动携带的问题状态

- **CHAR-Q02｜部分解决**：共同阶段、身份契约、最低节点结果形式、逐节点前置、独立技能进化、节点单级／多级与升级／后继并行已确认；具体层数、终点语法、完整等级候选、成长内容与数值等仍待定。
- **CHAR-Q03｜已解决**：常规角色节点选择窗口不提供放弃（CHAR-58）；“未来若设计放弃则应有补偿”不构成当前放弃或补偿方案。特殊入口、窗口外拒绝／退出及无合法候选时的处理未由此确认。
- **CHAR-Q04｜部分解决**：融合路线自身身份、形态与后续成长、合格节点进入常规候选，以及特殊机缘允许节点调整、默认从新合法随机候选改选已确认；具体融合入口条件、源技能处理、改选范围／代价／返还／后继依赖及其他可逆性仍待定。“按依赖关联成组调整”未获确认。
- **CHAR-Q05｜部分解决**：角色主动由玩家选择携带，每个占一个有限槽位，只能在指定调整时机更换已确认；已获原版与上位版默认共携、显式局部冲突例外由 CHAR-57 确认。具体槽数、扩展、角色差异、输入、允许窗口与更换生命周期仍待定。
- **CHAR-Q08｜已解决**：技能进化方式逐技能／节点设计，增强、变形、替换等不构成统一操作模板或封闭枚举；具体技能内容及后继规则另待设计。
- **CHAR-Q12｜已解决**：已获原版与上位角色主动默认可以共同携带，各占一个槽；显式局部冲突可以互斥，不能仅凭版本身份禁止共携（CHAR-57）。等级转移、版本保存、输入及其他生命周期仍待定。

### 14.9 跨系统重抽待定项与下一讨论坐标

- **GROW-Q01｜待定**：重抽道具的正式名称、数量／使用次数／持有与存放限制、来源与预算、成本、候选权重、合法池不足时的重叠细则；只一至两条合法武器方向时的实际重抽效果与成本、是否重洗武器先天词、退出／撤销／返还及无合法候选时的处理均未确认。GROW-09～11 的局内留存、整组重抽与上一组回避，以及 GROW-13 的四类用途不重开；常规附魔候选不足与整个合法池为空的处理另与 ENCH-Q04 关联。

**ENCH-Q03｜部分解决**：ENCH-12～18 与 GROW-13 已确认附魔的辅助定位、常规候选与同名升级、先看候选后选目标、当场应用、同参位目标资格、每个候选至少有一个当前可应用目标及共享重抽；具体来源、频次、代价与特殊附魔内容及规则仍待定。

当前下一项跨系统讨论为 **ENCH-Q04｜待定：常规附魔整个合法候选池为空时，如何处理这次机会**。该问题也追踪候选不足、放弃／退出／返还／补偿等尚未确认的处理，并关联 GROW-Q01；当前不预设任何方案。问题由武器报告负责，本报告只引用讨论坐标，不新增武器规则或代价；角色节点、留存重抽和武器附魔仍保持各自职责。CHAR-Q12 的默认共携与 CHAR-Q03 的常规节点不放弃均已解决，不继续作为下一问题。

## 15. 未采用的全局方案

- **固定主路线＋副路线槽位**：未采用。它能降低平衡与 UI 难度，但会把高自由度构筑压缩成预设职业模板。
- **前期开放、中期强制承诺一条主路线**：未采用为全局规则。它能形成清晰阶段感，但会关闭随机转向空间，并可能让前期投入被动失效。
- **所有路线自由获取且最终全部点满**：未采用。开放路线不等于取消机会成本；有限机会和深度前置必须继续存在。
- **用孤立机制结果替代融合路线**：此前的助手比较方案未获确认，已撤回；当前按 CHAR-50 保留融合路线的身份、形态与后续成长。
- **全部融合入口仅来自特殊机缘**：对话中的临时选择已被用户纠正并撤回；当前按 CHAR-51 与其他节点同样判断合法资格，允许常规窗口出现，仍保留逐节点特殊来源限制。
