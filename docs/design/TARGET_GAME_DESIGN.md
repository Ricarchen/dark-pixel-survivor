## 1. 一句话愿景

一款以角色个人故事为内容单元、采用俯斜视实时动作战斗的独立 PC 肉鸽：玩家在清晰的碰撞空间中走位、手动使用正手武器，并通过角色专属技能网络、手工命名武器谱系中的随机机缘与多神通 S 级武器，把一局构筑直接塑造成不同的弹道、范围、攻击节奏和屏幕形态。

## 2. 玩家体验

玩家每次进入一局时，需要同时面对三种张力：

1. **动作张力**：移动、瞄准、正手攻击、武器主动、换位与危险规避都由玩家即时完成。
2. **随机适应**：玩家可以为某条路线提前准备，但不能保证获得目标机缘；随机出现其他合法路线时，需要转向、接受次优协同或放弃机会。
3. **身份成长**：角色技能、专属武器、关卡、怪物与 Boss 都来自同一个人物主题，使数值成长同时表现为角色身份与战斗方式的变化。

游戏追求的不是“刷到最大数字”，而是让玩家在一局中亲眼看到：

- 单发攻击如何变成新的攻击节奏；
- 弹道如何改变空间控制方式；
- 角色技能如何改变玩家愿意承担的风险；
- 正副手如何形成不同战斗层次；
- 多道武器神通如何独立共存并在少量明确关系中融合；
- 一套构筑如何从局部效果成长为能够改变整个屏幕形态的体系。

## 3. 宏观玩法循环

```text
选择已解锁角色，或进入可试玩角色的解锁关卡
        ↓
进入角色个人故事关卡
        ↓
实时战斗：移动／瞄准／正手攻击／副手自动／主动技能
        ↓
击杀敌人并获得经验、武器机会、事件与商店资源
        ↓
并行但分窗的成长
├─ 普通经验：每级角色基础属性
├─ 经验里程碑：额外的常规角色技能窗口
├─ 精英／Boss／剧情／机缘：稀有角色机会
├─ 武器机会：+、附魔、命名谱系与换装
└─ 高阶机缘：A→S、后续同参、S锻造
        ↓
精英、Boss、剧情转折与阶段变化检验构筑
        ↓
通关／失败／进入无尽
        ↓
横向解锁角色、路线、武器、融合、剧情、外观与挑战
        ↓
下一局重新构筑，不携带永久伤害或生命加成
```

## 4. 四个核心系统

### 4.1 角色

角色不是一组基础属性，而是一套完整内容包的中心。

每个角色至少包含：

- 一个清晰的身份、矛盾与个人故事；
- 一套决定其操作风险与战斗节奏的核心机制或规则；
- 一张规模可变的专属技能进化网络；
- 一个专属武器家族与低阶开局原型；
- 一个与其主题匹配的个人故事关卡；
- 一组能映射其经历、敌对势力或心理变化的怪物、精英与 Boss；
- 一套低难度解锁角色、高难度扩展横向内容的挑战结构；
- 能够随技能状态、武器形态和高阶进化产生明显变化的角色表现。

角色技能网络负责角色的行为、状态、运行规则与可选资源循环，例如移动、施法、生命代价、防御、召唤、主动技能、角色状态，以及通过公开接口让武器攻击承载角色来源效果。它不会代替武器的命名进化、附魔或 S 级神通。

一局内不设固定主路线或副路线。玩家可以在所有已解锁且满足局部前置的母路线之间自由投资：有限的角色成长机会形成广度成本，路线内部的深度前置形成专精成本。融合只连接明确相近的路线，没有融合时每条母路线仍能独立成立。

角色成长采用共源分窗混合制：普通经验每级仍提供基础属性，在配置里程碑额外打开角色技能窗口；精英、Boss、剧情与特殊机缘提供稀有突破或融合。部分节点还可以要求本局战斗行为，或限定特定机缘才能进入候选／获得，但这些行为记录不会变成第二条经验或局外数值。

特殊条件采用分层公开。常规内容显示完整条件和进度；稀有节点、融合与特殊 A 初次至少给出来源或剧情线索，首次发现后在图鉴中永久公开完整条件；只有极少数非核心彩蛋可以完全隐藏。核心路线与重要 S 同参不能依赖完全隐藏内容，图鉴知识也不会增加概率或战斗数值。

每条母路线虽共享进入、深化、质变和终点四种成长职责，但必须先建立自己的路线身份契约；契约至少覆盖基础核心循环、空间与成长表达，并进一步说明角色共核联系、独立战斗闭环、可选局部规则与开放力量载体。语义阶段、节点内容种类、节点操作与融合关系彼此独立：获得新主动、获得新被动、新增效果或进化既有技能都可以服务于不同阶段，不能用同一条四节点直线反复换皮。

同一角色的所有母路线共享角色共核，但每条路线必须在共核之上形成不同、完整且不依赖融合的战斗闭环。主动、被动、效果和技能进化只是构成闭环的节点材料；路线可以采用不同力量载体与局部运行规则，但不被固定成资源循环，也不被固定成“直接技能／自身强化／武器附效”三类模板。局部机制不必拥有独立数值条，专用 HUD 只在持续决策确有需要时增加。

角色路线可以让武器攻击承载角色来源效果，但这不会把效果自动变成武器先天词、附魔、`+强化`、命名进化、同参、神通、锻造或兵装共鸣。效果由角色持有并动态作用于当前合法武器；武器与路线可以有契合差异，但母路线的成立不能以绑定具体实例或某类武器为前提。

前后均为合法载体时，普通换装与换手不清空角色准备或刷新冷却；已施加角色效果不因普通换装被清除或刷新，按自身规则结束；暂时没有武器承载时仍照常计时。具体强化自身决定适用技能／攻击与承载手位：已讨论的关键有限次数强化限于当前正手，持续附毒例子允许正副手；武器主动产生符合条件的攻击时也可使用强化。有限次数默认按一次发动消耗一次，多段不重复扣除。上述例子不是固定效果分类；多段覆盖、命名进化／A→S、标签与完整结算仍待定，详见 CHAR-33～38、CHAR-Q09～11。

### 4.2 武器

武器同时承担即时操作、随机适应与长线构筑三项职责。

- 正手由玩家手动控制，并在武器具有主动技能时释放；副手自动攻击且拥有不同表现。
- 新获得武器的主动技能有很短的启用等待，普通攻击不受该等待限制；具体时长与起算点待定。有主动技能的武器通常较强，作为内容方向保留，不设置固定品级门槛。
- D/C/B/A/S 是不同命名武器的固定底盘，不是同一件武器不断变色。
- 低阶武器沿可分化、可汇聚的手工谱系成长；路线数量不固定。
- A 级既可以从低阶谱系进化，也可以只由特定机缘或掉落直接获得；直接获取不跳过后续 S 突破。
- 每把 A 首先是一把完整武器，再从自身代表性特征中提炼一道 S 级神通。
- 第一把 A 形成 S 与第一道神通；后续同参 A 逐个炼入同一把 S。
- 同参位只收目标 S 同参集合的 A 级武器，位内武器不参战，武器仅在正手／副手参与战斗。默认无需供体亲自参战；少量供体可显式配置炼入前战斗淬炼，但不改变同参位非战斗的边界，具体培养流程待定。
- 零附魔供体满足其他培养／突破条件后照常炼入，只加入神通而没有附魔带入，不增加先附魔的门槛。
- S 不继续升为 SS/SSS；无尽上限来自多神通、明确融合、附魔、普通强化与有限整体锻造。
- 通用武器向所有角色开放，专属武器负责最直接地表达角色身份；两者使用同一强度预算。
- S 锻造保留稀有、高代价数值完善原则；具体机会来源、出现节奏和代价均待定，献祭或高风险试炼只作候选例子。

武器系统保留真正随机。玩家可以研究谱系并提前附魔，但不能锁定下一条进化路线。公平来自完整预览、所有候选都能独立运行，以及允许玩家放弃机会，而不是目标路线保底。

### 4.3 关卡

关卡首先是角色个人故事的战斗化表达，而不是可替换背景。

- 场景空间决定角色和武器的优势距离、障碍利用与危险阅读方式。
- 普通怪形成持续压力与基础移动题；精英引入阶段性构筑检验；Boss 承担复杂机制、故事转折和高价值机缘。
- 怪物阵容、事件、商店与高阶机会应与角色故事和当前难度共同变化。
- 最低难度完成角色介绍与正式解锁；更高难度解锁新路线、武器、融合、剧情、外观与挑战。
- 标准模式应提供可完成的构筑弧线；无尽模式继续容纳多道 S 神通、后续锻造和更高压强。

关卡采用房间制、连续地图、半开放区域或混合结构尚未锁定。最终结构必须服务于俯斜视实时移动、密集但可读的投射物和角色故事节奏。

### 4.4 战斗与怪物

战斗采用清晰碰撞空间上的高密度实时动作：

- 玩家需要持续移动、瞄准和管理正手主动，而不是只观察自动攻击。
- 副手、角色被动、召唤物和残留场提供自动层，但不能夺走正手操作的重要性。
- 构筑变化需要直接显示在人物状态、武器动作、弹道、命中、残留区域和屏幕控制范围中。
- 视觉装饰、实际伤害区和敌方危险预警必须分层，避免高密度效果掩盖碰撞信息。
- 普通怪、精英和 Boss 需要承担不同的战斗问题，不能只通过生命和伤害倍率区分。

怪物生态与最终视觉规范尚未讨论完成。现有血月墓地敌人只作为原型验证资料，不自动成为目标游戏首发内容。

## 5. 成长系统边界

| 成长层 | 负责内容 | 不负责内容 |
|---|---|---|
| 普通经验升级 | 生命、防御、移动、基础伤害等角色基础属性 | 命名武器进化、S神通 |
| 角色技能网络 | 角色行为、状态、局部规则、主动、角色来源武器附效、路线终点与角色路线融合 | A级武器、武器实例成长记录、武器神通谱 |
| 武器谱系 | D/C/B/A命名武器、正副手表现、随机进化 | 角色技能节点 |
| 玩家附魔 | 为已经存在的武器行为添加或强化构筑效果 | 凭空创造缺失的神通规则 |
| S级神通 | 主动、弹道、触发、攻击形态、状态与规则变化 | 普通属性升级 |
| S整体锻造 | 整把S已有数值底盘的高代价提升或重分配 | 新规则、新弹道、新主动 |
| 局外解锁 | 角色、路线、武器、融合、剧情、外观、挑战 | 永久生命、伤害等纵向碾压 |

这些系统可以通过公开战斗事件和标签双向协同，但不能相互取代。例如角色可以产生“主动损失生命”事件供武器响应，角色来源效果也可以读取武器攻击或命中事件；两者都不会让角色节点直接变成某把武器的一道神通或一条附魔。

## 6. 单个角色内容包的宏观模板

```text
角色主题与个人矛盾
├─ 角色共核／同一角色全部母路线共享的主题、基础战斗语言与底层规则
├─ 角色技能网络
│  ├─ 若干拥有独立闭环的母路线
│  │  └─ 各自可选的局部规则与开放力量载体
│  ├─ 开放式跨路线投资
│  └─ 少量明确的相近路线融合
├─ 专属武器家族
│  ├─ 多条D/C/B/A命名谱系
│  ├─ 若干A级同参及各自神通
│  └─ 一把或一组剧情定义的S级终极表达
├─ 个人故事关卡
│  ├─ 场景空间
│  ├─ 普通怪生态
│  ├─ 精英／事件／商店
│  └─ Boss与剧情转折
├─ 难度与横向解锁表
└─ 角色、武器、技能与剧情的视觉演变
```

角色武器家族既可以体现同类武器的技术发展，也可以记录人物不同人生阶段使用的武器。若角色心理或身份发生重大断裂，剧情阶段可以选择同器蜕变、善恶双相同参或彻底分裂为两套谱系，系统不预先写死。

## 7. 一局内的预期成长弧线

具体时间与数量尚未锁定，但宏观职责应保持：

### 前期：建立生存方式

- 通过普通经验补足基础属性；
- 认识角色核心机制；
- 获得或强化低阶正副手武器；
- 开始押注角色路线、附魔和武器分枝，但不能保证目标结果。

### 中期：形成构筑身份

- 角色技能网络出现明确母路线；
- 命名武器从低阶分枝到 B/A；
- 随机候选迫使玩家在原计划与临场高质量机缘之间权衡；
- 正副手关系、后天附魔与随机武器分枝开始形成组合；低阶进化的非直系附魔继承仍需后续确定。

### 后期：完成标准局核心表达

- 角色至少形成一个清晰的高阶路线结果；
- 有机会完成第一把 A→S 或其他等价的大型构筑转折；
- Boss 用空间、节奏和机制检验构筑，而不是只检验伤害总量。

### 无尽：拓展上限而非增加新字母

- 获取后续同参 A 并向现有 S 注入更多神通；
- 触发少量明确神通融合；
- 培养第二套武器或通用 S；
- 承担高代价 S 锻造、重铸与风险重铸；
- 面对不断改变空间问题的敌人组合与阶段规则。

## 8. 局外结构

局外成长只做横向扩展：

- 完成最低难度个人故事后正式解锁角色；
- 更高难度解锁新的角色路线、融合边、武器谱系节点、通用武器、剧情、外观与挑战；
- 解锁内容进入未来对局的合法内容池，不直接赠送一局内的最终形态；
- 不提供永久伤害、生命、防御等数值天赋树；
- 玩家长期成长主要来自知识、操作、对谱系的理解和可选择内容的扩展。

## 9. 目标与旧原型的边界

目标游戏与外部旧原型共享的是验证过的体验问题，例如：

- 手动正手与自动副手能否共存；
- 生命代价、吸血与范围技能能否形成风险收益；
- 怪海、精英、Boss和奖励窗口的基本循环；
- 投射物、预警和命中反馈的可读性。

目标游戏不自动继承以下原型限制：

- Phaser/Web 作为最终平台；
- 单个巨大场景类承担全部系统；
- 纯平面俯视图形表现；
- 仅血法师、五分钟 Easy 和单一路线内容；
- 当前写死的技能、Boss奖励、武器池和数值节奏。

## 10. 当前完成度与下一步

已形成：

- 产品定位与核心体验；
- 宏观成长分层；
- 武器品级、命名谱系、随机进化、先天词、附魔、同参、S神通与锻造的概念骨架及首份完整系统报告；
- 角色故事关卡、横向局外成长与无尽模式的大方向。
- 角色共核、每条母路线独立战斗闭环、非强制资源化和开放力量载体的角色网络原则。

尚未形成：

- 角色来源武器附效的多段覆盖、完整攻击匹配与其余生命周期；普通换装、手位与适用条件、按发动扣次等已部分确认；
- 角色技能进化网络的剩余节点语法与具体机会预算；
- 标准局关卡结构、时长、精英/Boss/商店节奏；
- 怪物生态与视觉规范；
