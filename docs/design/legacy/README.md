> 内容类型：外部历史事实与仓库边界

本目录用于标记外部历史原型与本设计仓库之间的边界。本仓库不包含旧 Phaser 代码或概念资产，也不会移动或删除外部项目中的用户文件。

## 外部历史快照

- 外部旧项目曾使用 Phaser、TypeScript、Vite 和 Vitest 验证部分战斗循环。
- 最近一次记录的旧原型分支为 `feature/dark-survivor-mvp`，快照提交为 `7025fa6733cd6c93272db462581785b3755d47b9`。
- 旧项目曾包含混写实现、旧讨论与长期设想的 `README.md`、原型 `src/`，以及早期 `assets/concepts/`。
- 上述路径和分支属于外部旧项目，不描述本仓库 `main` 的目录或当前状态。

## 隔离原则

- 旧资料保留作为体验验证、实现参考和历史记录，不直接删除或覆盖。
- 旧资料中的一项规则只有在新讨论中再次确认后，才进入目标游戏设计。
- 目标宏观设计维护在 `docs/design/TARGET_GAME_DESIGN.md`。
- 目标详细决策维护在 `docs/design/GAME_ARCHITECTURE.md`。
- 本仓库根 `README.md` 是目标设计索引，不是旧原型说明。
- 未来建立独立 PC 实现时，应从目标设计重新搭建技术架构，而不是直接扩张旧原型的单场景结构。
