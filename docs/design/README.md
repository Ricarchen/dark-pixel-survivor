# 设计文档索引

本目录将“目标独立游戏”与“现有 Phaser 原型”分开维护。

## 目标游戏

- [目标游戏宏观设计](./TARGET_GAME_DESIGN.md)：先看这一份。描述整体玩法循环、角色、武器、关卡、成长层级与内容生产单位。
- [详细设计决策账本](./GAME_ARCHITECTURE.md)：保存已确认细则、待定项、已废止规则和当前讨论位置。
- [角色技能进化网络设计报告](./systems/CHARACTER_EVOLUTION_NETWORK.md)：角色母路线、开放式投资、混合成长窗口、特殊资格、候选边界与融合的权威报告。
- [武器系统完整设计报告](./systems/WEAPON_SYSTEM.md)：武器系统的权威流程、来源限定 A、继承矩阵、边界、数据要求与未决问题。

## 设计治理

- [设计报告治理规范](./DESIGN_GOVERNANCE.md)：规定每份报告的状态、版本、必备章节、例外与验收标准。
- [设计追踪矩阵](./DESIGN_TRACEABILITY.md)：记录文档版本、决策依赖、下游影响、原型映射与待复核队列。

## 旧原型隔离区

- [旧原型边界说明](./legacy/README.md)：说明根目录 `README.md`、Phaser 代码与概念资产如何作为历史验证资料保留。

## 更新纪律

1. 宏观方向变化时，先更新 `TARGET_GAME_DESIGN.md`。
2. 每一小段讨论确认后，立即更新 `GAME_ARCHITECTURE.md` 中对应的稳定编号。
3. 系统细则同步更新对应的独立系统报告与 `DESIGN_TRACEABILITY.md`。
4. 旧原型中的规则不会自动进入目标设计，必须经过重新讨论和确认。
5. 文档确认不等于功能已实现。
