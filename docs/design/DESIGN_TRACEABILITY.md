## 2. 设计基线 DGB-0.1.10

本基线包含：

- 独立 PC 俯斜视实时动作肉鸽的产品方向；
- 角色故事关卡与横向局外解锁；
- 角色技能网络与武器神通谱职责独立；
- 角色网络采用开放式多路线投资，不设全局主／副路线槽位或中期强制锁定；
- 角色路线的广度成本来自有限机会，深度成本来自局部前置；
- 角色成长共用普通经验来源但分开结算：每级基础属性、里程碑常规角色窗口、精英/Boss/剧情/机缘稀有窗口；
- 部分角色节点可以要求本局战斗行为或指定机缘，且资格、出现与获得必须分开记录；
- 特殊内容分层公开：常规完整显示，稀有先给线索并在发现后图鉴解密，只有极少数非核心彩蛋完全隐藏；
- 图鉴永久知识不改变内容解锁、候选概率或战斗数值；
- 每条母路线共享进入、深化、质变和终点四种语义职责，但节点数量、分枝和图形不固定；
- 每条母路线必须以基础身份契约记录核心循环、空间与成长表达，并进一步说明角色共核联系、独立闭环、可选局部规则和开放力量载体；仅换包装即可互换的路线必须合并或重做；
- 语义阶段、节点内容种类、节点操作与融合关系彼此独立；角色网络至少支持获得新主动、新被动、新增效果和进化既有技能，且结果形式可扩展；
- 同一角色的所有路线共享角色共核，但每条母路线必须在共核上形成不同、完整且不依赖融合的战斗闭环；
- 路线可以拥有局部状态或运行规则，但不强制建立数值资源，也不默认采用积攒—消耗；专用 HUD 条只在持续决策确有需要时增加；
- 直接技能、自身强化、角色来源武器附效等只是开放力量载体，不是固定路线模板；节点材料或载体差异不能替代闭环差异；
- 角色可以通过公开接口让武器攻击承载角色来源效果，但该效果不自动进入任何武器成长层；效果归角色所有，动态作用于当前合法武器；
- 角色路线不绑定具体武器实例，也不以某类武器作为完整战斗闭环的必要条件；武器与路线可以有契合差异；
- 前后均为该效果合法载体时，普通换装／换手保留角色准备与冷却，已施加角色效果不因普通换装被清除或刷新，无载体时计时照常；
- 承载手位与技能／攻击适用条件按具体强化区分：用户指出的关键有限次数强化限定当前正手、持续附毒可允许正副手，例子不构成固定二分法；
- 本轮有限次数强化出手按发动扣一次，挥空不返还，多段命中不额外扣；覆盖范围逐强化定义；
- 合格范围命中可向多个实际命中目标分别附效，重施方式逐效果声明；毒火持续伤害不能互相施加、叠加或刷新，不扩写成所有递归规则；
- 技能进化逐技能与节点设计，兼容关系和冲突组局部声明；节点前置允许组合条件或不同抵达路径；
- 随机角色窗口直接从当前合法节点池给出有限具体候选，不先锁路线或设类别配额；等权与固定数量未确认；
- 正常角色节点选择窗口不提供放弃，条件性的“若将来有放弃则应补偿”没有启用该功能；武器进化放弃仍独立保留；
- 部分机缘可提供本局保留的重抽机会或道具，骰子仅为例子；同一机会适用于普通属性、角色节点及武器进化候选，整组从当前合法池重抽；
- 重抽优先避开紧邻上一组，合法池不足时允许重复；不由放弃换取，不确认累计历史排除、目标保底、等权或跨局保留；
- 相关母路线可从相关子节点开辟具有后续成长与区分度的融合路线，原母路线仍可独立成立；
- 融合入口及后续可进入常规合法池，具体特殊来源限制保留；“全部融合入口来自特殊机缘”的临时选择已撤回；
- 多数节点单级、取得后退出候选，部分关键节点可多级成长；升级与后继并行，具体后继可有等级前置；
- 特殊机缘允许改选本局节点，默认提供新合法随机候选；调整范围、代价和依赖处理未定；
- 新主动或上位版本由玩家选择携带，角色主动每技能一槽，仅在指定调整时机更换；已获得的原版与上位默认可共携，显式局部冲突可以排除；槽数、窗口与生命周期仍未定；
- 新武器主动技能有短暂启用等待，普通攻击不受该等待影响；主动通常对应较强武器只是内容目标，无固定品级门槛；
- 正手手动、副手自动的双武器结构；
- 同参位只接纳目标 S 的同参 A，位内不战斗；武器只有装备在正手或副手才参与战斗。默认无需供体亲自参战，少量内容可配置炼入前战斗淬炼，淬炼期间仍只通过正副手参战；
- D/C/B/A/S 固定命名底盘；
- A 可以由低阶进化、机缘／掉落直接获得或两者兼有；部分 A 可以没有低阶进化入边；
- 武器进化只筛当前武器的直接合法上位，一／两个时全部展示，超过两个时随机给两个不同方向；两个是提供数量，不是谱系出度上限；
- 超过两个合法方向时目标不保证出现，重抽也不保底，为目标提前准备附魔不提高其抽取概率；完整预览与候选独立有效继续保留；
- 角色合法池随机与武器局部条件随机保留临场选择，玩家仍可规划；不把全部武器进化改成全自主选择，也不再要求每次武器进化必随机迫使转向；
- 放弃武器进化消耗本次机缘，保留当前武器及先天词／附魔并获得普通 `+1`；其他强化来源未取消；
- `+强化`、先天词、后天附魔、命名谱系彼此正交；
- 所有以 D/C/B 为来源的合法命名进化，包括进入 A，旧 `+` 等级统一减一且最低零；A→S 与后续同参仍清除输入 A 的全部 `+`，S 自身 `+` 按原规则保留；
- 完全直系进化可完整保留附魔；非完全直系进化中仍适用的附魔按当前等级比例折损，允许降至零并移除，不保底一级；对目标不兼容者在接受进化时直接失去，不休眠或转换；
- 非完全直系的附魔处理不覆盖首次 A→S 全部附魔及等级保留或后续同参选中一条附魔及等级带入；逐附魔完整后果预览仍有效；
- A 同参、单一 S 多神通、显式融合；
- 零附魔供体可以正常炼入，神通必定加入，仅不发生供体附魔带入；
- 专属与通用 S、跨武器兵装共鸣；
- S 无随机先天词，高代价有限数值锻造；
- 标准模式与无尽模式的宏观职责。

本基线不包含：

- 角色技能网络的完整节点语法；
- 角色附效出手前取消／中断、完整丢弃／重新装备、命名进化与 A→S 生命周期，以及合法武器、具体攻击匹配、其余归因／递归、强度与 UI 细则；
- 节点等级数量与内容、完整等级候选、融合具体门槛与源技能处理、改选范围及依赖；
- 角色主动的具体槽数、调整窗口、具体局部冲突配置、版本保留、等级转移、冷却与既有效果处理；
- 重抽机会的具体来源、名称、数量、次数、上限、费用与本局保存方式，合法池不足时的重复细则，以及只有一／两个武器方向时重抽的实际效果与费用；
- 武器先天词是否随候选重抽、其他随机字段或商店库存是否适用，以及重抽退出／撤销／返还与无合法候选处理；
- 附魔的基础获得与升级渠道，非完全直系等级折损比例／取整／曲线、完全直系关系判定及兼容标准；
- 新武器主动启用等待的时长、起算点、重复拾取／装备与进化适用范围；
- 同参位的数量与完整培养、战斗淬炼流程；
- S 锻造的具体机会来源、节奏和代价；“献祭一把未装备 A”与“完成高风险锻造试炼”只保留为候选；
- 标准局具体时长与奖励机会密度；
- 首个角色、武器家族或关卡的最终内容数量；
- 商店经济、怪物生态和 Boss 规范；
- 最终引擎、渲染方式与代码框架。
