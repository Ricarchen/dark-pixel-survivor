## 2. 设计基线 DGB-0.1.7

本基线包含：

- 独立 PC 俯斜视实时动作肉鸽的产品方向；
- 角色故事关卡与横向局外解锁；
- 角色技能网络与武器神通谱职责独立；
- 角色网络采用开放式多路线投资，不设全局主／副路线槽位或中期强制锁定；
- 角色路线的广度成本来自有限机会，深度成本来自局部前置；
- 角色成长共用普通经验来源但分开结算：每级基础属性、里程碑常规角色窗口、精英/Boss/剧情/机缘稀有窗口；
- 部分角色节点可以要求本局战斗行为或指定机缘，且资格、出现与获得必须分开记录；
- 特殊内容分层公开：常规完整显示，稀有先给线索并在发现后图鉴解密，只有极少数非核心彩蛋完全隐藏；
- 图鉴永久知识不改变内容解锁、候选概率或战斗数值；
- 每条母路线共享进入、深化、质变和终点四种语义职责，但节点数量、分枝和图形不固定；
- 每条母路线必须以基础身份契约记录核心循环、空间与成长表达，并进一步说明角色共核联系、独立闭环、可选局部规则和开放力量载体；仅换包装即可互换的路线必须合并或重做；
- 语义阶段、节点内容种类、节点操作与融合关系彼此独立；角色网络至少支持获得新主动、新被动、新增效果和进化既有技能，且结果形式可扩展；
- 同一角色的所有路线共享角色共核，但每条母路线必须在共核上形成不同、完整且不依赖融合的战斗闭环；
- 路线可以拥有局部状态或运行规则，但不强制建立数值资源，也不默认采用积攒—消耗；专用 HUD 条只在持续决策确有需要时增加；
- 直接技能、自身强化、角色来源武器附效等只是开放力量载体，不是固定路线模板；节点材料或载体差异不能替代闭环差异；
- 角色可以通过公开接口让武器攻击承载角色来源效果，但该效果不自动进入任何武器成长层；效果归角色所有，动态作用于当前合法武器；
- 角色路线不绑定具体武器实例，也不以某类武器作为完整战斗闭环的必要条件；武器与路线可以有契合差异，但合法武器与攻击范围、触发条件及生命周期仍待定；
- 正手手动、副手自动的双武器结构；
- 同参位只接纳目标 S 的同参 A，位内不战斗；武器只有装备在正手或副手才参与战斗。默认无需供体亲自参战，少量内容可配置炼入前战斗淬炼，淬炼期间仍只通过正副手参战；
- D/C/B/A/S 固定命名底盘；
- A 可以由低阶进化、机缘／掉落直接获得或两者兼有；部分 A 可以没有低阶进化入边；
- `+强化`、先天词、后天附魔、命名谱系彼此正交；
- A 同参、单一 S 多神通、显式融合；
- 零附魔供体可以正常炼入，神通必定加入，仅不发生供体附魔带入；
- 专属与通用 S、跨武器兵装共鸣；
- S 无随机先天词，高代价有限数值锻造；
- 标准模式与无尽模式的宏观职责。

本基线不包含：

- 角色技能网络的完整节点语法；
- 角色来源武器附效在普通换装、换手、丢弃、命名进化和 A→S 中的具体生命周期，以及合法武器、攻击范围、归因、递归、强度与 UI 细则；
- 同参位的数量与完整培养、战斗淬炼流程；
- S 锻造的具体机会来源、节奏和代价；“献祭一把未装备 A”与“完成高风险锻造试炼”只保留为候选；
- 标准局具体时长与奖励机会密度；
- 首个角色、武器家族或关卡的最终内容数量；
- 商店经济、怪物生态和 Boss 规范；
- 最终引擎、渲染方式与代码框架。
